# 第7章 积极型投资者的证券组合策略：主动的方法

## Core Idea
积极型投资的超额收益只能来自三个经验验证过的领域——**不受欢迎的大公司（低市盈率）**、**廉价证券（价值≥1.5倍价格）**、**特殊情况（套利）**——且必须符合两项优势标准：(1) 达到基本稳健要求；(2) 明显不同于大多数投机者的策略。成长股投资被整体否决：专业基金都跑不赢指数，智力一般的个人更没有理由。

## Frameworks Introduced

- **成长股的严格定义**（修订版脚注）：至少连续5年每股净利润年均增长率 ≥ 15%——"预计未来兴旺"不构成定义，只是"一厢情愿的想法"（如同赛期结束前称某队为冠军）；过去满足不能保证将来满足
- **否定成长股的双重论证**：
  1. **基金对照检验**：1961–1970年，45家10年以上记录的成长基金平均收益108% vs 标普综合105%、道指83%；1969–70年126种成长基金大多跑输两指数——分散化投资成长股"并不能带来优异的回报"
  2. **两个结构性困难**：① 好前景已被市场发现并计入价格（当期市盈率20倍以上）——判断正确也得不到好结果；② 快速增长不可能永久持续，规模扩大后增长曲线必然平缓甚至下降
- **低市盈率（不受欢迎的大公司）策略**：
  - 逻辑：市场高估出色的股票 → 必然相对低估暂时失宠的公司（"股市的一条基本规律"）
  - 必须是**大公司**：小公司可能始终无盈利能力，或利润改善却长期被忽视；大公司有两个优势——资本/人力度过难关重新获利；市场对任何改善迅速反应
  - 操作：取道指10种市盈率最低的股票，持有1–5年，每年按原则转向
  - 证据（1937–1969，Drexel 34次检验）：明显跑输道指仅3次、持平6次、25年明显超过；1936年$10,000 → 1962年低市盈率组$66,900 vs 高市盈率组$25,300 vs 道指$44,000
  - **已知失效窗口**：1968年底–1971年6月检验，低市盈率组巨额亏损而高市盈率组获高利润——结论未推翻，但建议"先采用低市盈率的想法，再增加其他定量定性要求"
- **廉价证券（bargain issues）**：根据分析确立的事实，价值至少比价格高出50%
  - 两条估值标准：① 评估法（未来利润估计×适当系数）；② 私人所有者价值法——强调资产可实现价值，尤其**净流动资产/营运资本**
  - 低估的成因：当期令人失望的结果 + 长期被忽视或不受欢迎（市场"喜欢小题大做，把普通波动夸大为严重倒退"）
  - **纯净流动资产标准**（最易识别）：售价 < 扣除优先债务后的净营运资本——买主没为固定资产和商誉付钱；1957年约150种；1957年12月买入85家持2年：组合涨75%（标普425涨50%）、无一严重亏损、78家明显上涨
- **二类企业廉价证券**：二类企业 = 未在重要行业占据领导地位的企业
  - 为什么总被低估：1931–32年萧条后投资者偏爱领头羊、对次要企业失去兴趣——"任何价格都太高，因为它们是走向消亡的"（与1929年"蓝筹股任何价格都不高"同样夸大）
  - 获利五渠道：① 股息回报高 ② 再投资利润相对支付价格较大（5–7年显效）③ 牛市低价证券也水涨船高 ④ 平淡期价格调整使被低估者回归应有水平 ⑤ 令人失望的因素被纠正（新情况、新政策、管理层变动）；外加收购溢价（多元化收购"几乎总是表现出较大的慷慨"）
- **特殊情况（special situations）**：收购（收购价大幅高于现价）、破产重组套利（旧债券成本 vs 重组计划公布后"发行前"市场的差价）、法定拆分（1935年公用事业控股公司法——拆分后企业价值大幅上升）；根因：市场系统性低估"涉及任何复杂法律诉讼"的证券（"永远不要购买涉及法律诉讼的证券"对投机者稳妥，对公众则制造廉价机会）

## Key Concepts
- **全价购买禁令**：不要按"全价"买三类证券——外国债券、一般优先股、二类普通股（含初始发行）；全价≈面值或公允业务价值；防御型无论价格如何都回避，积极型只按低价买——**低价 ≤ 评估价值的三分之二**
- **防御/积极没有中间地带**："你不可能成为较好的'半个经营者'并期望投资带来相当于正常业务一半的利润"——折衷态度"更可能带来失望而非收获"
- **成长股的风险特征**：公司投资质量多年不变，但"股票的风险特征依赖于股市变化"——公众热情越高、股价上涨相对利润越快、风险越大；巨额财富几乎总归与公司有密切个人联系者（雇用/亲属关系）——外部投资者每次下跌都会被迫检讨"投入是否过多"
- **克莱斯勒陷阱**：利润极不稳定 → 形势好时价格高、市盈率低（看似"低市盈率"实为异常）；利润接近0时市盈率必然很高——低市盈率名单须辅以"股价相对过去平均利润较低"的过滤
- **"事后看到的利润"vs"实际得到的利润"**：Anaconda电缆——利润与股价齐跌后并不自动反弹（1956年$85 → 1962年$23.5 → 1963年被$33收购）；稳妥要求：过去10年利润无赤字年份 + 足够规模财务实力

## Mental Models
- **用基金成绩作上限标尺**：个人成长股投资的结果不可能好于专业成长基金——"根本没有理由使人相信"智力一般者（即使投入大量精力）能胜过拥有更多智慧和更好研究手段的机构
- **两端的偏见对称**：1929年"蓝筹股任何价格都不高"与1930年代后"二类企业任何价格都太高"是同一种错误的两个方向
- **摆锤论**：1946年二类股从被低估摆到被高估（标普低价股涨280% vs 道指涨40%），1961、1968年又在更小企业新股上重演——狂热与冷落的交替是常数
- **内部人 vs 外部人的持有逻辑**：控制权（内部人）视角下二类企业是合理的私人投资；独立小股东按"企业价值"全价买入则不明智——两种地位决定两种策略
- **中心价格指导**：二类证券围绕"大大低于公允价值"的中心水平波动——以历史中心价位而非公允价值指导买价

## Anti-patterns
- **把成长股当积极策略**：即使"判断正确"，预期利益已包含在股价中；1961–70年基金整体未跑赢指数
- **只看到利润股价齐跌就抄底**：利润可能不反弹（Anaconda电缆）——必须叠加10年稳定性+规模财务实力检验
- **追逐高市盈率热门股**：20世纪20年代、1946、1961、1968年的剧本重复四遍，每次以崩盘收场
- **在中间地带摇摆**：想做"半个投资者"——既不肯防御型的研究与纪律，又没有积极型的知识与时间
- **按"企业价值"全价买二类股**：外部股东必须等廉价条件（≤2/3评估值），"实际经验是最有说服力的"
- **把克莱斯勒式波动股当低市盈率**：利润近零时市盈率必然畸高、利润高峰时市盈率畸低——异常股扭曲名单

## Worked Example
**低市盈率组合的复利效应（1936–1962）**：
- $10,000 按"每年转向10种最低市盈率道指股"操作 → $66,900（26年约7.5倍）
- 同额投10种最高市盈率股 → $25,300；同额投道指全部30种 → $44,000
- 廉价股在34次年度检验中25年明显跑赢道指；但1968–71窗口反转——方法有效≠永远有效，需辅以其他要求

## Key Takeaways
1. 积极型只做三件事：低市盈率大公司、价值≥1.5×价格的廉价证券、特殊情况套利——每件都需要相应的知识禀性
2. 成长股是"一厢情愿"的代名词：定义需要5年15%的硬数据，基金证明分散化成长股跑不赢指数
3. 低价买=股价≤评估值的2/3；全价买三类证券（外国债、优先股、二类股）是防御型也须回避的错误
4. 低估来自"当期失望+长期忽视"，但必须叠加10年利润稳定性与规模检验
5. 防御与积极之间没有中间档——多数人该诚实选择防御型
6. 低市盈率策略有失效窗口（1968–71），需要持续检验而不是信仰

# 第10章 投资者与投资顾问

## Core Idea
证券投资是独特的业务——它几乎总是在某种程度上依赖他人的建议，但**"请人告诉我如何赚钱"是天真的**：商人在自己业务的各个方面寻求专业建议，却从不指望别人告诉他如何获利——获利是他们自己的职责。投资顾问的正确角色是防止失误、确保程式结果；任何"优于平均水平"的承诺都是越界。

## Frameworks Introduced

- **依赖他人建议时的两条安全路径**：
  - 路径一：把自己与顾问**严格限制于程式、保守甚至有些枯燥的投资方式**，或只对非常熟悉和信任的人言听计从
  - 路径二：增长自己的知识和经历，获得独立判断他人建议的能力——此时你已从防御型**转变成了积极型投资者**
  - 判定：普通业务/职业关系下接受非程式建议的唯一条件，是"他本人的知识和经历得到了增长，因此有能力对他人的建议做出独立的判断"
- **投资顾问的职责边界**：利用训练获得的高超技能和经验"防止客户出现失误，并确保他们获得应有的投资结果"（正常/程式收入）；真正专业的著名咨询公司承诺保守、不声称比别人聪明，"引以自豪的地方在于细心、稳健和称职"；主要目标是长期保留主要价值+稳健收入增长——**"它们对客户的主要作用在于防止客户出现惨痛的失误"**
- **金融分析师的正确使用**：分析师对投资者的价值"主要取决于投资者自身的态度"——提出正确的问题才得到正确的答案；向分析师清楚地表明自己是"具有价值意识而不是价格意识的人"，其建议才可能真正有好处
- **防御型/积极型与顾问的关系**：
  - 防御型：通常没有能力独立判断建议，但可以"明确地（甚至是不断重复地）说出自己想购买哪几种证券"——高等级债券+著名公司普通股（价格不太高者）
  - 积极型：要求顾问详细解释建议、坚持表达自己的判断；只在极罕见情况（顾问品德能力被证明完全可靠）下接受不理解的决定

## Key Concepts
- **建议来源的五层光谱**：亲属朋友 → 本地银行家 → 经纪公司/投资银行 → 金融服务机构/金融期刊 → 投资顾问——"这一系列繁杂的来源表明，在投资者的心目中，目前还没有一个逻辑化的或系统化的方法"
- **金融服务公司的两面性**：穆迪、标准普尔等是"相当于统计机构的服务"——汇编的数据为所有重要证券分析提供基础，但面向从最保守到最大胆的客户，"很难坚守一个明确的或根本性的理念"
- **市场预测的供给定律**：多年预测"没有任何人将这种活动当真"，但它们会"熟练地使用模棱两可技巧——无论未来结果怎样，这种技巧都能成功地加以应对"——"除了揭露证券市场上的人性之外，并没有什么实际意义"；"既然已经有了需求，必然会产生供给"
- **经纪业的根本矛盾**："华尔街的兴旺主要来自于投机，而股市投机者整体上几乎都要亏钱"——经纪公司不可能完全以专业为基础经营（否则业务下降）；最盈利的客户需要投机建议，公司思维随之"紧密追随日常市场交易"——"证券公司极力想帮助客户赚钱，而根据数学定律，客户在这一领域最终几乎必然是要赔钱的"
- **客户经纪商（注册代表）**：品德优良、掌握大量证券知识，但其业务是获取佣金，因此"几乎无法避免投机性思维"——真正的投资者必须清楚（以言语和行动）告诉对方对"秘密消息"不感兴趣
- **CFA（特许金融分析师）**：1963年底设立——通过规定考试（证券分析和资产组合管理）并满足合格标准，仿照CPA——推动分析师工作"以真正的职业为基础"
- **投资银行业务的正当性**：为企业扩张提供新资本——"保持股市活跃的理论依据就在于：有组织的证券交易所有利于新发行的债券和股票的销售"
- **个体购买者的保护真空**：大额新证券由金融机构（银行/保险公司）购买，面对"精明并有经验的购买者"，交易以商业化条件完成；但个体购买者"经常是缺乏经验并且很不精明的"——"公众投资者的保护并不在于其自身的判别能力，而在于发行公司的良心和道德"

## Mental Models
- **把"如何赚钱"排除在咨询之外**：投资顾问提供的是防错和保底，不是致富之路——"只有当投资者要求获得高于平均水平的投资回报时，才会带来如下问题：所要求的或所承诺的是否过头了？"
- **业务收入决定立场**：佣金的数学定律——经纪公司帮助客户在投机领域赚钱的愿望与其佣金结构天然冲突
- **价值意识 vs 价格意识**：问"某种股票是否稳妥"的含义经常是"随后几个月有没有可能上涨"——被价格问题扭曲的分析师"并不利于健全的思维或得出有价值的结论"
- **用招股说明书看穿推销**：SEC规则要求披露所有信息，但"所要求的大量数据，通常会使得招股说明书过于冗长而令人生畏"——只有少数个人投资者认真阅读，"投资行为仍然不是取决于自己的判断，而是主要取决于向他们推销这些证券的机构所做出的判断"
- **选择顾问 ≈ 选择证券**："选择一个满意的普通顾问，与自己独立地选择恰当的证券几乎是一样困难"——不赞成向亲属朋友寻求建议

## Anti-patterns
- **把"近期经营有利"当买入理由**：金融服务公司普遍态度——"如果认为企业近期业务活动处于有利条件就应购买，无论当期价格如何"——"这种肤浅的原则，经常会妨碍专业人士提供有意义的分析"
- **跟随"技术预测"服务**：完全（或几乎完全）通过技术方法预测市场运行的公司——与本书定义的"投资者"无关
- **相信推销员的判断**：1959年警告→1960–61和1968–69年"数量空前的低质股按荒唐的高价卖给公众"——几家重要华尔街公司参与了"不太光彩的行为"；"贪婪、愚昧和不负责任等行为并没有从金融舞台上消失"
- **与濒临破产的经纪公司往来**：1970年前后交易所成员公司破产潮——合伙人以本应用于保护客户的资本投机（"为赚取双倍利润"），"这种行为是不可原谅的"
- **不付咨询费却期望超额收益**："大多数证券购买者并没有通过支付特定的费用来获取投资建议。因此，按道理讲，大多数情况下，他们不能够也不应该预期获得优于平均水平的结果"

## Worked Example
**1970年经纪行业危机**：
- 相当一部分交易所会员公司破产或濒临破产（至少两家大公司）——半个多世纪以来首次
- 表面解释（交易量激增导致结算压力）不成立：1970年成交量29.37亿股是有史以来最大（1965年前任何一年的两倍多），而15年牛市期间年平均"只有"7.12亿股却迎来行业最大繁荣
- 真正原因：合伙人的大部分资本以投机性的普通股形式持有，1969年市场下跌时资本随之消失——"这些资本原本是为了防止经纪行业通常的金融危机给客户造成损失的"
- 对策：只与交易所会员交易；无保证金账户者通过银行交割证券（购买时指示经纪商交付付款银行，出售时指示银行收到款项后交付证券）——"从安全和放心的角度看，这种花费是值得的"

## Key Takeaways
1. 求咨询是防错，不是求富——"如何赚钱属于他们自己的职责范围"
2. 依赖他人建议的两条路：严格程式化，或增长知识获得独立判断（=成为积极投资者）
3. 向分析师提正确的问题，并明确自己是价值意识而非价格意识
4. 经纪公司受佣金结构驱动，对"惊人收益"的承诺保持警觉
5. 防御型投资者至少能说出自己只买什么：高等级债券+价格恰当的著名公司普通股
6. 只与交易所会员交易，通过银行交割证券

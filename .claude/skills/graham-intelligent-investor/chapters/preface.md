# 序：第4版序（巴菲特序 + 怀念本杰明·格雷厄姆）

## Core Idea
本版开卷是沃伦·巴菲特亲笔序言：投资成功不需要顶级智商、超凡商业头脑或秘密信息，只需要**稳妥的知识体系作为决策基础 + 控制情绪的能力**——本书给出知识体系，情绪约束必须自己做到。附巴菲特1976年悼文与兹威格生平简介中的核心原则，共同确立全书基调：**股市越愚蠢，守纪律的投资者机会越大；从愚蠢中获利，而不是成为愚蠢行为的参与者**。

## Frameworks Introduced

- **投资成功的两要素公式（巴菲特版）**：
  - 知识体系（本书提供，准确而清晰）+ 情绪约束（"是你自己必须做到的"）
  - 何时用：任何"为什么学了方法还是亏钱"的问题——先检查情绪是否侵蚀了体系
  - How：遵从格雷厄姆倡导的行为和商业准则，**重点读第8章和第12章的建议**（巴菲特点名）

- **愚蠢市场机会定律**：
  - "能否获得优异的投资成果……也取决于在你的投资生涯中，股市的愚蠢程度有多大。股市的行为越愚蠢，有条不紊的投资者面对的机会就越大。"
  - 何时用：市场出现明显非理性时——那正是机会密度最高的时候，不是离场的时候
  - How：遵从格雷厄姆的建议，从股市的愚蠢行为中获利，而不是成为愚蠢行为的参与者

- **兹威格总结的四条核心原则**（生平简介中归纳，可视为全书浓缩）：
  1. 股票不是交易代码，而是对实实在在企业的所有权；内在价值不依赖于股票价格；
  2. 市场像钟摆，永远在短命的乐观（股价过贵）和不合理的悲观（股价过廉）之间摆动——聪明投资者向乐观主义者卖出、从悲观主义者手中买进；
  3. 每笔投资的未来价值是其现在价格的函数——付出的价格越高，回报就越少；
  4. 无论多么谨慎，每个投资者都免不了犯错；只有坚持"安全性"原则——**无论一笔投资看起来多么令人神往，永远不要支付过高的价格**——才能使犯错的几率最小化。投资成功的秘诀在于你的内心：批判性思考、不相信华尔街的"事实"、以持久的信心投资。说到底，**你的投资方式远不如你的行为方式重要**。

- **原则的稳定性检验**：
  - 证券分析领域的研究成果发表后"仅在几个星期或几个月内就会看上去非常可笑"，而格雷厄姆的原则40年间"一直是稳妥的"；金融风暴摧毁不可靠的知识体系之后，这些原则的价值经常得到提升并更好地被理解。
  - 何时用：评估任何新投资理论时——问它是否经历过风暴的检验，而不是看它刚发表时多漂亮

## Key Concepts
- **知识体系 vs 情绪**：投资成功的两个独立变量——书给前者，后者只能自己修炼
- **为后人栽树的人**：沃尔特·李普曼所说"为后人栽树的人"，巴菲特认为格雷厄姆就是——"如果你需要鼓励和忠告，就可以随时去找他"
- **每天三件事**：格雷厄姆80岁前的愿望——每天做"傻事、有创造性的事和慷慨的事"；他的想法是强有力的，但表达方式"无疑是温和的"
- **广泛智力活动的副产品**：格雷厄姆的支配地位不是来自全神贯注于单一目标的狭隘思维，而是来自几乎无法定义的广泛智力活动
- **格雷厄姆-纽曼公司**：1936–1956年退休期间年收益率不低于14.7%，高于同期股票市场12.2%的整体收益率——跻身华尔街有史以来最佳长期收益率之列（注：其后记所述20%为未扣除管理费之前的收益）

## Mental Models
- **把市场当愚蠢的交易对手**：股市的行为越愚蠢，有条不紊的投资者面对的机会就越大——愚蠢是资源，不是风险
- **把"方法"与"为人"分开评估**：格雷厄姆的思想强有力但表达温和——好思想不需要用傲慢包装
- **用风暴检验理论**：金融风暴摧毁不可靠的知识体系后，真正的原则价值会提升——这也是为什么这本书在每次危机后更被珍视

## Anti-patterns
- **以为成功需要顶级智商、商业头脑或秘密信息**：巴菲特明确否定——这些都不是必要条件
- **情绪侵蚀体系**：有最好的知识体系，却让贪婪/恐惧摧毁它——巴菲特说这是读者唯一必须自己做到的事
- **支付过高的价格**：无论一笔投资看起来多么令人神往——"安全性"原则的唯一禁令

## Worked Example
**巴菲特的自我经历**：1950年年初，19岁的巴菲特读了本书第一版，"当时我认为它是有史以来投资论著中最杰出的一本。时至今日，我仍然认为如此。"——此后他选择哥伦比亚大学、终生追随格雷厄姆；悼文中说格雷厄姆对他一生的影响"仅次于我的父亲"。

**格雷厄姆1919年的教训**（生平简介）：Savold轮胎公司上市首日赚250%，同年10月爆出欺诈丑闻，股票变得一文不值——从此他变成"对股票进行微观研究（甚至是细致研究）的大师"。1925年他发现北部管道公司每股含至少80美元的债券、股价仅65美元：买进、敦促管理层提高分红、3年后以110美元卖出。

## Key Takeaways
1. 投资成功 = 稳妥的知识体系 + 情绪控制；本书提供前者，后者只能靠自己
2. 结果还取决于股市的愚蠢程度——股市越愚蠢，机会越大；做从愚蠢中获利的人
3. 巴菲特点名精读第8章（市场波动）与第12章（每股利润）
4. 价格越高，回报越少；"无论多么令人神往，永远不要支付过高的价格"
5. 用风暴检验任何理论：经不起危机考验的体系不值得信任

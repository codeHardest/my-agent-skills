# 第12章 对每股利润的思考

## Core Idea
两条相互矛盾的忠告构成全章框架：**①不要过于看重某一年的利润；②如果确实关注短期利润，请当心每股利润数据中的陷阱**。用美国铝业1970年报解剖"每股利润"如何被稀释、特殊扣除、税收把戏扭曲成四个不同数字——"公司会计经常是需要慎重对待的；证券分析会非常复杂；股票估价只有在非常罕见的情况下，才是真正可靠的"。

## Frameworks Introduced

- **每股利润的四重面孔（以美国铝业1970年报为例）**：
  - 基本利润 $5.20（注释篇幅是基本数据的两倍）
  - 净收益（扣除特殊费用）$4.32
  - 完全稀释后（未扣除特殊费用）$5.01
  - 完全稀释后（扣除特殊费用）$4.19
  - 解读顺序：先看稀释（可转换债券/权证行使后利润下降一半甚至更多的情况屡见不鲜），再判断特殊费用的归属——"我们并不知道这一部分有多少，因此，我们不能恰当地说出这一年的实际利润"
- **平均利润法（对抗会计花招的良药）**：
  - 采用过去7–10年平均利润：缓和商业周期波动；"它几乎可以解决所有特殊费用和利益的问题"——这些损益中大多数代表企业营运历史的一部分，应包含在平均利润中
  - 增长率计算：**近3年平均数与10年前相应数据对比**（遇到特殊费用/利益问题用折衷方法）
  - 应用：美国铝业1961–70十年平均每股利润$3.62；1964–70七年平均$4.62；近3年/10年前对比增长率141%（复合9.0%）
- **两步分析法的实战（美国铝业）**：
  - "以往业绩价值" = 道指的10% = 每股$84（道指1970年收盘$840）→ 当时$57.25的价格"似乎很有吸引力"
  - 但高级分析师该为未来不利影响调低多少？"坦白地讲，我们并不清楚这一点"——美国铝业案例"在一定程度上表明，上一章中我们对典型工业企业评估方法可靠性的怀疑是有道理的"

## Key Concepts
- **特殊扣除的两处巧妙**：①预期未来亏损被提前扣除——"它们不属于1970年，因为它们并不是在这一年实际发生的。它们也不会在实际发生的那一年出现，因为它们已经被公布出来了。做得干净利落，但是，难道这没有误导性吗？"②注释从不谈减税作用——若亏损在税收优惠前扣除，未来利润不仅不必承担扣除，还会因约50%的税收优惠而增加
- **"只记录晴朗的时光"**：只要某企业在某一项业务亏损，就可作为"特殊项目"扣除，使"基本利润"只含盈利项目和业务——"正如国王爱德华七世的日规一样"
- **冲销时机的系统性游戏**：1970年市场血雨腥风、人人预期业绩差、华尔街预期1971年好转——"多么巧妙的安排：从不好的年份中尽量加大扣除（早已被遗忘而成为了往事），从而使得随后年份的数据非常可观"
- **历史对比（或有储备 vs 特殊扣除）**：旧做法从好年份提"或有储备"平滑利润（会计师正当反对：扭曲实际利润，"每年结果要如实公布，平均或均衡的工作应该留给股东和分析师自己去做"）；新做法相反——把损失全塞进坏年份，让好年份"从头再来，显示出令人高兴的每股盈利"
- **损害可比性的六个会计因素**：①特殊扣除 ②以往亏损导致的所得税扣除下降（未来利润免税）③可转换债券/权证稀释 ④折旧方法（直线 vs 加速——Trane公司1970年利润增长近20%中一半来自改用直线折旧，仍用加速折旧申报所得税以递延纳税）⑤研发成本扣除的时间选择 ⑥存货估价FIFO vs LIFO
- **盈利能力与市盈率的硬约束**："只有当企业的盈利能力高于平均水平时，才能维持较高的市盈率"——美国铝业资本利润仅达平均水平或更低，是市场给它低市盈率的决定性因素

## Mental Models
- **把利润报告当谈判文件来读**：注释与数据同样重要——美国铝业的注释"压根儿没有谈到这些亏损未来的减税作用"；该扣除却不说税收影响的报告是单方面陈述
- **警惕"为未来做储备"的反向操作**：为未来亏损做储备，除税收优惠外不会给以后年份净收益带来增加额——但很多投资者把"一次性冲销"理解为"未来利润更干净"，正中管理层下怀
- **微小变化无关紧要**：某一年的结果微小变化（道氏化学21美分项目使增长率9%变4.5%）"不可能对未来的平均利润或增长产生任何影响，也不可能对企业的稳妥和现实的估价产生任何影响"——华尔街"甚至本身微不足道的项目都被他们看得很严重"
- **便宜与否要按真实利润算**：62美元的价格÷表面利润=10倍，÷真实利润（Q4 70美分年化）=22倍——"市盈率"只有利润数字可信时才有意义

## Anti-patterns
- **以Q4年化外推全年**：美国铝业Q4"基本利润"$1.58看似好于上年——扣特殊费用后仅$0.70，年化$2.80而非$6.32
- **忽略稀释**：转换权（及认股权）可使公布利润下降一半甚至更多——"金融服务公司并非始终会考虑到股权稀释这一因素"
- **把特殊扣除当不存在**：西北工业一次性冲销$2.64亿（每股约$35，为市价两倍）——若不考虑它豁免的近50%所得税与双倍稀释，对盈利能力的判断完全失真
- **只看当期增长数字**：近20%的利润增长可能一半来自折旧方法变更——"该公司的每股利润比1969年增长了近20%，但是其中一半的增长，来自于重新使用了较古老的直线折旧法"
- **因短期利润微小变化做买卖决策**：季度/年度数据的关注"必然会对投资者的思维产生影响"——正是本章要教育的内容

## Worked Example
**美国铝业的估值谜题（1959–1971）**：
- 1959年：股价$116 = 利润的45倍（西尔斯仅20倍）——"显然其未来的增长已经被市场价格严重高估了"
- 1970年：利润增长非常可观（10年复合9%，略优于西尔斯、大优于道指），但市场只给11.5倍（西尔斯27倍、道指15倍多）
- 1970年底价格恰好是1959年最高价的一半，同期西尔斯涨到3倍、道指涨约30%；1971年从$70跌到$36（账面值$55）
- 教训：低市盈率与高市盈率都可能是错的——"市盈率的历史"本身是判断市场预期的核心材料；华尔街对美国铝业的悲观（相对其优秀记录）和1959年的狂热（45倍）一样，都是情绪定价

## Key Takeaways
1. 别只看一年的利润；要看7–10年平均利润——它能消化大部分会计花招
2. 每股利润至少拆成四层：基本/净收益/完全稀释/扣除特殊费用后
3. 特殊扣除与减税作用必须一起读——"为未来做储备"可能让未来利润虚高
4. 增长率用"近3年平均 vs 10年前"计算，特殊项目采用折衷
5. 低市盈率≠便宜：先确认利润数字没有被折旧、存货、研发时间选择美化
6. 对大多数投资者而言，最好的方法"是确保自己购买的证券物有所值，并且这样保持下去"

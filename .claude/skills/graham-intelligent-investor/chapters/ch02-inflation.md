# 第2章 投资者与通货膨胀

## Core Idea
通胀不能成为"股票必然优于债券"的理由：55年的数据表明，通胀率与股票利润/价格之间**不存在密切关联**；债券与股票的配比决策应回到第1章的25%–75%程式框架，而不是被通胀恐惧推着走。

## Frameworks Introduced

- **通胀-股票相关性检验框架**：面对"通胀利好股票"的流行说法，不凭直觉，而是直接对比历史数据——通胀区间内股票利润和价格是否同步上涨？
  - How：取多个5年期数据段（本表为1915–1970，55年、11个时段），分别比较批发价格/消费价格变动 vs 股票利润/价格变动
  - 结论：1966–1970年生活费用上涨22%（1946年以来最大5年期涨幅），股票利润和价格反而双双下降；其他时段也呈类似的无规律关系

- **资本利润率检验**（验证"通胀提升企业盈利"论）：
  - 衡量口径：公司税后利润 ÷ 有形资产账面值
  - 数据：过去20年道琼斯成分股约10%；按当期市价（1971年市值900 vs 账面560）计算约6.25% → 市盈率18倍
  - 关键发现：尽管批发价格上升40%，公司资本利润率并未上升——过去20年利润的大幅增长全部来自再投资形成的资本增长，而非通胀红利

- **两害相权取其轻**（防御型投资者的配置决策）：
  - "完全持有债券的风险更大"——即使债券利率（7.5%）当前优于股票，防御型投资者仍须配置相当比例的股票，因为大规模通胀的可能性存在
  - 股票提供的通胀保护大于债券，但绝不能指望股票能"恰当"对冲通胀

## Key Concepts
- **"它们会起伏不定"（they will fluctuate）**：摩根名言——股票利润和市值不会按固定速度（4%或其他任何速度）增长，买在今天的价格可能多年无满意回报（通用电气1929–1932崩盘后25年才收复失地）
- **公司债务膨胀**：1950–1969年公司净债务增长近4倍，税前利润仅增一倍多；息后税前利润 ÷ 债务额从30%跌到13.2%——利率上升时代，债务是重要的负面经济因素
- **公用事业在通胀中的两难**：成本上升+价格管制受损，但其单位成本增速低于价格指数，且依法可收取足够回报的费用，战略地位反而较强
- **通胀预期陷阱**：相信通胀会深化的人，会把牛市上涨看成"通胀假说的证明"而持续买入（不管价位多高、股息多低）——"这种做法必将带来灾难"

## Mental Models
- **用历史区间检验关系，而不是用单一牛市叙事**：1915–1920（物价翻倍）是最严重通胀期，1965–1970只有15%涨幅——通胀在55年间反复出现又消失，未来也不会是一条直线
- **警惕"新范式"论证**：任何时代最危险的推演都是"因为X，所以这次股票永远涨/债券永远跌"
- **把通胀当作不确定因素而非可预测变量**：假设未来数年通胀率约3%（历史平均2.5%的合理外推），据此配置而非豪赌
- **不买自己不懂的防通胀资产**：黄金（35年涨35%）、钻石/名画/稀有硬币（报价人为且不可靠）、房地产（难以分散化、易被误导）——"在介入之前，先确定自己是熟悉这一领域的"

## Anti-patterns
- **"债券本质上是不可取的投资形式"**：与早前"信托只能买债券"的极端同样错误——优质股票不可能在任何条件下都优于债券，反之亦然
- **因通胀恐惧而全仓股票**：忽视市场已经过高、股息率已低于债券利率的事实
- **把贵金属/收藏品当"投资"**：花67500美元买一枚标注1804年（并非该年铸造）的硬币，很难被想象为投资行为
- **用"通胀假说"为自己的追高开脱**：新一轮牛市时把"涨"解读为通胀证明，不断买入

## Worked Example
**1966–1970 通胀与股票的背离**：这5年生活费用上涨22%（1946–1950年以来最大），是"通胀利好股票"论的最佳检验——结果股票利润与价格整体下降。此前多个5年期则呈现相反的组合。→ 通胀与股票表现无稳定关系。

**公司债务表（表2-2，1950–1969）**：净债务 $140亿 → $693亿（近4倍），税前利润 $42.6亿 → $91.2亿（约2倍），资本利润率 18.3% → 11.8%。→ 通胀期间企业实际利润率不升反降；巨额新增债务（成本仅4%）是利润中很大一部分的来源，剔除杠杆后股权回报更低。

## Key Takeaways
1. 通胀率与股票利润/价格没有密切关联——"通胀利好股票"是未经数据检验的假设
2. 债券与股票的配置回到程式框架：25%–75%区间，对半开为默认，不因通胀恐惧走极端
3. 按市价计算股票盈利收益率（E/P）并与债券利率比较，是配置决策的核心输入
4. 防御型投资者优先目标是把风险最小化，而不是在两类资产间赌方向
5. 通胀预期是心理陷阱：它让人在错误的时间以错误的价格买入
6. 黄金、收藏品、房地产不是可靠的防通胀工具，且多数超出普通投资者的能力圈

# 第11章 普通投资者证券分析的一般方法

## Core Idea
普通投资者不需要成为分析师，但**必须能听懂分析师在说什么**、并区分"表面分析与深入严谨的分析"。本章给出两套核心工具：债券/优先股的安全性标准（以过去利润的保障倍数为核心），以及普通股的估价框架（未来平均利润 × 资本化因子）——并坦率指出：数学估价法在最不可靠的领域最流行。

## Frameworks Introduced

- **债券/优先股安全性标准（最低保障倍数）**：
  - 评价公司债券的主要标准：**以往某些年份的利润为利息总支出的倍数**；优先股为利润对债券利息+优先股股息之和的倍数
  - 表11-1（投资级债券，税前）：公用事业经营公司 7年平均4倍、最差年份3倍（税后2.65/2.10）；铁路与零售企业标准略低（税前约3.2–4.3倍区间）
  - 投资级优先股：利润对"固定费用+**两倍**优先股股息"的比值须达同样标准——因为股息不可扣税而利息可扣税
  - 不适用群体：公用事业控股公司、金融类企业、房地产公司
  - **利率时代的替代标准**：8%利率下工业企业要达到7倍保障更困难——改用"所获利润占债券本金的百分比"：税前比率 工业33%、公用事业20%、铁路25%；"最差年份"要求约为7年要求的三分之二
- **估价的三个补充标准**：
  1. 规模（业务规模+城市人口的最低标准）
  2. **股票与权益比**：次级股市值 ÷（债务或债务+优先股）总面值——次级投资承受不利影响时提供的"缓冲"
  3. 财产价值：正式被看做债券的首要保障，但经验证明多数安全性取决于盈利能力；仅对公用事业（利率取决于财产投资）、房地产、投资公司是重要的独立标准
- **普通股估价二步法**：估算未来几年平均利润 → 乘以恰当的"资本化因子"；标准做法先确定过去产量/价格/毛利平均数，再以GNP预测+产业特有方法外推销售额
- **成长股估价公式**：**价值 = 当期（正常）利润 ×（8.5 + 2×预期年增长率）**（增长率为随后7–10年预期）——"并不是说这个公式给出了成长股的'实际价值'；只是说它大致给出了现在正流行的复杂计算方法所得出的结果"
  - 反解用途：由当期市价反推市场预期的增长率（表11-5：施乐预期32.4% vs 通用汽车2.8%）
  - **增长率8%悖论**：若假设无限期8%+增长，价值趋于无穷大、股价多高也不过分——估价者必须在计算中引入**安全性（margin of safety）**概念（"类似于工程师在构造方面的规定"），使实际增长率低于预测时购买仍能达标
- **两步评估过程（推荐的两阶段估价）**：
  1. 以"以往业绩的价值"为起点：公式计算过去盈利能力、稳定性、增长率、财务状况的权重（假设过去7年增长率随后7年不变）
  2. 按未来预期新情况修正——高级分析师定一般化公式、初级分析师算单公司数值、高级分析师再判断业绩偏离程度并调整价值
  - 为什么值得做：改进现行做法、积累经验与见解、像医药领域那样靠记录促进更好方法产生

## Key Concepts
- **资本化率的五个决定因素**：①总体长期前景 ②管理 ③财务实力和资本结构 ④股息记录 ⑤当期股息收益率
- **"管理"因素的真实权重**：华尔街大量谈论但"实际上并没有多大的作用"——无法客观量化检验时只能模糊考察；把它作为独立因素"通常很容易导致严重的价值高估"；**只有最近情况变化且影响尚未反映在数据中时，管理因素才重要**（克莱斯勒1962年接管后每股利润$1.24→$17、股价$38.5→$200）
- **股息记录标准**：20年及以上连续支付记录是股票质量的重要有利因素——"防御型投资者可以只购买符合这一标准的股票"
- **标准股息政策**：通常利润的三分之二用于派息（1969年道指派发率59.5%、全美企业55%）；利润与股息关系正常时两者可互推估值（预期利润$3、股息$2 → 股价=利润12倍=股息18倍=$36）
- **保障倍数的经验可靠性**：铁路历史证明——几乎每个危机案例都涉及"长久债务过重"（繁荣期固定费用保障不够），而满足标准的铁路公司都走出了困境；唯一例外纽黑文铁路1947年重组时保障仅1.1倍，1961年第三次破产接管；宾州中央铁路早在1965年保障就不达标——"谨慎的债券投资者早该避开或抛售"
- **行业分析的局限**："华尔街对较远的未来的判断非常糟糕"——很难找到用"一系列令人信服的事实"证明热门行业即将崩溃或冷门行业即将繁荣的报告
- **证券分析 vs 金融分析**：前者=考察评估股票债券；后者=+投资政策制定（组合选择）+一般经济分析

## Mental Models
- **用群体估算对抗个体误差**："综合的或群体的估算，可能比对个体企业的估算更为可靠"——人们几乎不可能事先区分哪些个体预测可靠；"广泛分散业务的流行做法本身，就否认了人们对'选择性做法'的追捧"
- **数学方法的讽刺**：数学估价法"在人们认为它不太可靠的领域却非常流行"——对未来的预期越依赖估价法（对过去业绩依赖越小），越可能出错："在面对不太容易准确判断的情况时，如今的证券分析师就不得不使用数学和'科学'的方法"
- **想象力与保守的两难**："投资者无法做到两者兼得"——发挥想象判断巨额利润要承担错误计算的巨大风险；保守拒绝支付未来溢价，"必须准备将来为所放弃的绝佳机会而后悔"
- **利率是所有估价的底色**：未来利率假设更高，既定预期利润/股息的现值就更小——长期利率大幅波动使这种预测"近乎武断"，只能沿用老方法

## Anti-patterns
- **在利率上行时代放宽债券标准**：1965年版告诫——"我们并不认为，投资者可以永久性地依赖这种有利的环境；因此也不认为，投资者在挑选工业或其他企业的债券时，可以放宽自己的标准"（1963→1970年非金融企业利息支出$98亿→$261亿，占税前利润比重16%→29%）
- **给"管理"单独定价**：把管理层作为额外牛市因素单独考虑→严重价值高估（邓拉普式"起死回生者"可能是骗子）
- **以市场预期增长率买高成长股**：若实际增长未达预期（表11-5中4家公司的增长未达1963年价格预期），行市跑输道指——预测"不要错误地认为此类预测非常可靠"
- **把市盈率差异当真理**：1963年化学股市盈率（19.8–25.3倍）大幅高于石油股（10.2–16.3倍）——事后化学股利润实际下降而石油股大体实现预期——"化学股这个例子，证明了市盈率有可能是错误的"
- **依赖"行业前景"报告**：发掘的材料"一般都是公众非常熟悉的，而且已经对市场价格产生了重要的影响"——信息已定价

## Worked Example
**价值线预测的验证（表11-2，1964年6月→1968年）**：
- 对道指30只成分股1967–69年利润与"价格潜力"的预测：利润预测偏低（合计$52.00 vs 实际$56.26）但问题不严重；6年前那轮预测在利润/股息上过于乐观，但所用较小乘数抵消了影响，"价格潜力"预测与1963年实际平均价格大体相同
- 教训：群体估算的误差小于个体预测——基金因而广泛分散；个体预测"大幅度偏离目标"是常态

## Key Takeaways
1. 债券安全性=利润保障倍数+规模+股票权益比+（特定行业的）资产价值；满足严格标准的债券几乎总能应对未来变迁
2. 高利率时代用"利润占本金百分比"替代保障倍数（工业33%、公用事业20%、铁路25%）
3. 普通股价值=未来平均利润×资本化因子；成长股公式 8.5+2×增长率，且必须内含安全边际
4. 资本化率五因素中，"管理"最被高估——只在变化未入数据时有意义
5. 群体预测比个体预测可靠——广泛分散本身就是对"选择性"的否定
6. 预测都会错；价值来自"以往业绩价值+合理修正"的两步框架

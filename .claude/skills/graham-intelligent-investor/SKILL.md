# 聪明的投资者（本杰明·格雷厄姆）

本杰明·格雷厄姆 1949 年初版、1973 年第四版定稿的投资经典。全书方法论可在三句话内概括：**先确定自己是哪种投资者，再按对应标准选股；买入的唯一理由是价格明显低于价值（安全边际）；市场先生的报价只可利用，不可指导。**

## 核心框架（Front-loaded）

### F1 投资者身份二分（一切决策的第一步）
- **防御型投资者**：无时间/精力/兴趣——平衡配置（股票25%–75%，其余债券）+ 指数化 + 七项选股标准。目标：最少麻烦、合理结果。
- **积极型投资者**：愿意投入大量时间——在"不流行的业务"（廉价股、特殊情形、套利）中寻找超额回报。
- **用法**：任何"该买什么/怎么配"的问题，先判定对方属于哪类，再给对应方案。防御型绝不用积极型的方法。

### F2 安全边际（全书的中心思想）
功能：**使投资者不必对未来做出准确预测**。三种形态：
1. **利润保障**（债券/优先股）：税前利润 ≥ 总固定费用5倍以上（铁路标准；税后2.9倍），连续多年、包含较差年份；
2. **价值缓冲**（债券）：企业总价值 ≥ 3倍债务规模；
3. **盈利能力**（普通股）：预期盈利能力大幅高于债券利率——10年累积超额 ≈ 购买价50%为可靠边际。
- 分散化是放大器：单只证券可能亏损，20种以上具有安全边际的证券"总体利润超过总体亏损"的概率很大。
- 反例：1972年12倍PE=8.33%利润率+4%股息——安全边际不足；"有利条件下的投资"（繁荣期买当期高利润的劣质证券）是主要亏损来源。

### F3 市场先生（市场情绪模型）
你的合伙人每天都来报价，躁郁交替：狂躁时喊高价，抑郁时报低价。**他的报价只应被利用，不应被指导**——大涨不追，大跌不慌。市场价格往往荒谬，价值投资者利用荒谬。

### F4 防御型七项选股标准
1. 规模足够大（工业总资产$1亿/公用事业$5,000万）；
2. 流动比≥2:1（公用事业可放宽）；
3. 近10年每股利润无赤字；
4. 20年连续股息支付；
5. 10年每股利润增长≥1/3（期初vs期末，三年平均）；
6. PE≤15（过去7年平均利润，可用12个月利润近似）；
7. 价格≤1.5倍账面值，或 PE×P/B≤22.5。
- 道指30家仅5家全部达标——标准严格是特性，不是缺陷。防御型持有7家即可，但若标准在5年内失效，应放弃该只股票。

### F5 积极型三类业务（按难度排序）
1. **套利/资产清理**：不依赖市场行情；格雷厄姆-纽曼经验：≥20%回报、80%成功率；
2. **廉价普通股**：市值<净流动资产2/3，分散买入（100种）；"未来既无吸引力也无希望"的公司；
3. **廉价优质股**：二类公司+充足保障，评估价值2/3以下买入。

### F6 债券保障倍数标准
税前5倍（税后2.9倍）固定费用覆盖，连续多年——"保障必须经过多年检验，最好包含经济较差时期"。

### F7 成长股估值公式（仅供参考）
```
价值 = 当期正常利润 × (8.5 + 2 × 预期年增长率)
```
- 预期增长率必须保守；结果必须打折；"每当有人用到微积分或高等代数时，你就应该保持警觉"——复杂数学常是以理论代替经验。

### F8 预测法 vs 保护法
- **预测法**：预测未来趋势，靠判断力取胜——格雷厄姆不推荐。
- **保护法**：不预测，靠安全边际+分散化——"如果选对了，获利更多；如果选错了，也不至于失败"。

### F9 四条商业准则（决策四问）
1. 知道自己在干什么，通晓自己的业务；
2. 不让别人管理你的业务，除非能细致监控并理解其行为；
3. 没有可靠的计算就不要涉足；远离利益不大、亏损严重的业务；
4. 有勇气相信自己的知识和经验——"数据和推理正确，行为就是正确的"。

## 使用方法
- **评估个股**：先走防御型七项标准（F4）；若标的不达标但价格极低，切换积极型框架（F5 廉价股法）。
- **构建组合**：先定身份（F1）→ 平衡配置 → 分散化 → 每笔买入都要求安全边际（F2）。
- **识别泡沫/投机**：用F3（市场先生）、F6（保障倍数）、P6（数学警告）检验价格是否脱离价值。
- **检验管理层与股息**：支付约2/3利润或证明留存带来满意增长，否则低支付率就是低估的原因（1美元股息对股价影响≈1美元留存的4倍）。

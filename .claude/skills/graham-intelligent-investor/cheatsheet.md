# 速查表 Cheatsheet

## 身份判定（第一步永远先做）
- 有充足时间/精力/兴趣 → **积极型**（廉价股、特殊情形、对冲）
- 没有 → **防御型**（平衡配置+指数化+七项标准）
- 投机永远保持小规模、单独核算、自认投机者

## 防御型组合（四条原则）
1. 股票仓位：25%–75%，其他为债券（或等价物）
2. 每只股票投入比例：总资金1%–5%（避免单票风险）
3. 持有主要行业代表性公司（如道指30家）
4. 质量门槛+价格门槛（七项标准）

## 防御型七项选股标准
1. 规模足够大（总资产：工业$1亿/公用事业$5,000万）
2. 财务状况稳健：流动比≥2:1（公用事业可放宽）
3. 近10年无赤字（每股利润）
4. 20年连续支付股息（不间断）
5. 10年每股利润增长≥1/3（期初→期末，三年平均）
6. 市盈率≤15（过去7年平均利润；可用12个月利润近似）
7. 价格≤1.5倍账面值；或 PE×P/B≤22.5（更宽规则）

## 积极型三类选择（按难度排序）
- 套利/资产清理：不依赖市场行情，≥20%回报、80%胜率
- 廉价普通股：市值<净流动资产2/3、分散买入（100种）；"未来既无吸引力也无希望"的公司
- 廉价优质股：二类公司+充足保障（评估价值2/3以下买入）

## 债券安全标准
- 保障倍数：税前5倍（铁路债券）/ 税后2.9倍；连续多年、含较差年份
- 价值缓冲：企业总价值≥3倍债务
- 1972年现实：8.33%利润率+4%股息 < 应有安全边际

## 成长股估值公式（仅供参考）
```
价值 = 当期正常利润 × (8.5 + 2 × 预期年增长率)
```
- 预期增长率须保守；结果须打折；"每当有人用到微积分或高等代数时，保持警觉"

## 安全边际三种形态
1. 利润保障（债券）：税前≥5倍固定费用
2. 价值缓冲（债券）：总价值≥3倍债务
3. 盈利能力（普通股）：预期盈利大幅高于债券利率

## 股息政策检验
- 支付约2/3利润，或证明留存带来满意增长；否则低支付率=低估的原因
- 1美元股息对股价影响≈1美元留存的4倍

## 四条商业准则（决策四问）
1. 我通晓这门业务吗？
2. 我在亲自监控（或深信其品格能力）吗？
3. 计算可靠、利益不大亏损严重的业务远离吗？
4. 我有勇气相信自己的知识和经验吗？

## 操作纪律
- 市场先生：报价只可利用，不可指导
- 不预测：用保护法（安全边际+分散化），不用预测法
- 估算必须保守："与过去情况不同的估算，至少稍稍偏保守"
- 主要亏损来源：有利条件下买高价劣质证券
- 出售规则："出售后去纳税，比留在手中等待后悔要更好"

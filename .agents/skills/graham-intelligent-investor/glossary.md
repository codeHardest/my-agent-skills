# 术语表 Glossary

- **投资 (Investment)**: 以深入分析为基础，确保本金安全并获得满意回报的操作。不符合这三条的任何操作都是投机。
- **投机 (Speculation)**: 分析不足、本金无保障、回报不令人满意的操作。投机本身合法且不可避免，但投机者在意识自己是投机者并限制金额。
- **防御型投资者 (Defensive Investor)**: 没有时间/精力/兴趣做深入研究的投资者；采用平衡配置+指数化+七项标准的简单方法，以最低的麻烦获得合理结果。
- **积极型投资者 (Enterprising Investor)**: 愿意投入大量时间与精力；通过"不流行的"业务——廉价证券、特殊情形——获得超额回报。
- **安全边际 (Margin of Safety)**: 价格与评估价值之间的有利差额；使投资者不必对未来做出准确预测。全书的中心思想。
- **市场先生 (Mr. Market)**: 每天都来报价的躁郁症合伙人。他的报价只应被利用，不应被指导——你是否有机会做成交易，取决于他的报价多离谱。
- **预测法 (Forecast Approach)**: 试图预测未来趋势（下一步或多年），靠判断力战胜市场。格雷厄姆不推荐。
- **保护法 (Protective Approach)**: 不预测未来，靠安全边际+分散化保证结果——"如果选对了，获利更多；如果选错了，也不至于失败"。
- **内在价值 (Intrinsic Value)**: 由资产、利润、股息、前景等事实决定的"合理价值"——不是精确数字而是大致区间；分析师只能给出"大致的估计"。
- **盈利能力 (Earning Power)**: 对可保持盈利能力的估计，用多年平均收益修正当期收益；"过去的情况"是起点，"未来预测"要保守调整。
- **成长股 (Growth Stock)**: 过去每股利润增长优于平均水平、且预期将持续的公司股票。购买价必须对照其增长的可实现性；"预期利润"必须由过去的记录支持。
- **廉价股 (Bargain Issue)**: 价格低于内在价值三分之二以上的股票——通常来自"未来既没有明显吸引力、也不是明显没有希望"的企业。
- **净流动资产法 (Net Current Asset Value)**: 流动资产−全部负债 ≤ 购买价（即股价≤净流动资产的三分之二）；若在2/3以下价格买入并分散持有，回报与安全性俱佳。
- **账面价值 (Book Value)**: 资产负债表上的股东权益。分析起点而非结论；比市值更接近"实体价值"，但不是准确的内在价值指标。
- **市盈率 (P/E Ratio)**: 价格/每股利润。防御型标准要求过去7年平均利润的PE≤15（可用最近12个月利润近似）。
- **价格/账面值 (Price/Book)**: 股价/每股账面值。与PE组合成"PE×P/B≤22.5"的限价规则。
- **保障倍数 (Coverage)**: 税前利润/固定费用（利息+优先股息）。铁路债券标准：税前5倍（税后2.9倍）以上，且连续多年达到。
- **股票股息 (Stock Dividend)**: 代表特定利润再投资的资本化（通常≤5%），把价值从盈余账户转入资本账户；与股票分割有本质区别。
- **股票分割 (Stock Split)**: 改变普通股结构（通常2:1或3:1）以降低每股价格区间，与利润再投资无关。
- **商誉 (Goodwill)**: 收购中超过可识别资产的价值；在股价中体现为"承诺"。商誉越重要，企业实际价值越不确定。
- **可转换证券 (Convertible)**: 可在指定条件下换成普通股的债券/优先股。"两全其美必有其假"——用低于纯债或纯股的条款换取转换权。
- **权证 (Warrant)**: 以固定价格购买普通股的权利——"近似于一种欺诈行为"；其市场价值是对普通股"剩余价值"的一种扣除。
- **分散化 (Diversification)**: 安全边际的放大机制——单只证券可能亏损，但20种以上具有安全边际的证券组合"总体利润超过总体亏损"的概率很大。
- **留存利润 (Retained Earnings)**: 未分配利润。股息政策检验：支付约2/3，或管理层证明再投资带来满意的每股利润增长；1美元股息对股价的影响约为1美元留存的4倍。

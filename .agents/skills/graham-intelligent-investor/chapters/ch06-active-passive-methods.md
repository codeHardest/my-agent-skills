# 第6章 积极型投资者的证券组合策略：被动的方法

## Core Idea
积极型投资者的起点与防御型完全相同（高等级债券+高等级普通股），差异在于"消极面"——本章用一份**禁止清单**划定边界：低等级债券与优先股、外国政府债券、新发行证券，除非出现显著的折价或能通过非常规严格测试，否则不碰。

## Frameworks Introduced

- **积极型投资者的否定清单（什么不买）**：
  - 不买高等级优先股——让给有85%股息免税待遇的公司购买者
  - 回避低等级债券和优先股，除非价格有相当大的折扣：高息证券价格至少应比票面低30%；低等级债券折扣应更大
  - 不买外国政府债券（即使收益率诱人）
  - 小心对待一切新发行证券——包括很有吸引力的可转换债券/优先股、近期利润很好的普通股
  - 核心原则：**每笔非常规投资都必须有充分依据**；积极投资不存在唯一的理想模式，取决于个人能力、知识、兴趣

- **一级 vs 二级债券的判别标准（利息保障倍数）**：
  - 定义：发债公司利润 ÷ 全部利息费用；铁路财务充分安全要求 5倍
  - 案例：Chicago, Milwaukee, St. Paul and Pacific 铁路 5% 信用债券1964年售价68%、收益率7.35%，但利息保障仅1.5倍（1970年该公司报告大量赤字、暂停收益债券利息，债券跌到面值10%）
  - 用途：高收益必须用保障倍数检验，不能只看收益率

- **新股发行的牛市生命周期模型**（1959年版，1972年验证依旧）：
  - 牛市中途第一批新股定价较有吸引力 → 早期买家获巨额收益 → 升势继续，融资愈演愈烈、公司质量逐步走低、要价越来越夸张 → 最后"不知名小公司的发行价高出已上市多年的中型公司当期价格"——这是**牛市由盛而衰的可信信号**（且这些新股很少由信誉较高的大型投行操作）
  - 结果：价格崩盘，新股从发行价跌掉75%甚至更多；底部区域公众对小盘股的厌恶"如当初买进的狂热"——价格走向另一个极端

## Key Concepts
- **"商业性投资"（businessman's investment）谬误**：为了每年多1%–2%的利息承担本金损失——"如果你愿意承担风险，你必须确定能够在票面价值上获得实实在在的收益"；5.5%–6%的二级债券以票面价几乎肯定不能买，以70的价格买入"还差不多"——耐心总能等到
- **二级证券的两面性**：市场不景气时几乎全部遭重创；一旦形势好转又巨大反弹——1930年代积累巨额欠息的优先股在1945–47年繁荣中大多以现金或新证券弥补（Cities Service 6美元优先股1937年15美元、1943年27美元（累计股息$60），1947年可兑换196.50美元信用债券、售价186美元）
- **"需要收入"不是买劣质债券的理由**：历史经验——仅仅因利率较高而买缺乏安全性的债券或优先股是不明智的
- **外国债券的执行风险**：高等级外国债券（澳、挪威）无理由担心支付能力，但违约时"缺乏法律或其他手段来主张自己的权利"——古巴4.5%债券1953年$117买进，1963年跌到面值20%
- **新发行证券的审慎原则**：下单前"仔细评估和非寻常的严格测试"——两个结构性理由：(1) 总有承销商销售阻力；(2) 总在"市场有利"（对卖方）时发行
- **配售增发 vs 新上市**：已上市公司按比例配售，认购权有货币价值、通常被行使，无需大力推销；非上市公司上市则"根据控股方的需要"、趁市场有利兑现——风险既来自圈钱的公司，也来自"使圈钱得以发生的市场环境"

## Mental Models
- **用"禁止清单"定义积极型**：积极投资者最有用的一课是"不应该做什么"——把绝大多数诱人的东西排除后，剩下的选择自然简单
- **收益必须对应"实实在在的票面收益"**：多1%–2%利息换本金大跌是"糟糕的商业决定"——风险溢价必须算总账
- **时机错配观**：既然每一轮熊市都能以70甚至更低买到二级债券，"又何必现在以100左右的价格买进？——这种做法是违背常识的"
- **卖方有利=买家不利**：任何"市场有利"的发行窗口都是站在卖方一边的
- **拒绝新股是一种独立能力**："能够在牛市期间抵御新股发行商的花言巧语，这是成为聪明投资者的基本条件"

## Anti-patterns
- **以票面价买二级债券**：1946–47年10家铁路收入债券均价102.5，翌年跌到68（一年市值损失1/3）——该年铁路经营业绩比上一年好得多，下跌与行业背道而驰（仅因资本市场疲软）；缩水幅度大于当年道指跌幅（约23%）
- **买"高收益"当收入来源**："因为需要收入"而接受低保障倍数——高收益的代价是恐慌中无法坚持
- **为一点利率好处买外国债券**：捷克斯洛伐克8%债券的过山车：1922年96.5 → 1928年112 → 1932年67.75 → 1936年106 → 1939年6 → 1946年117 → 1948年35 → 1970年8——"拒绝这种债券不仅有利于自己，而且有利于自己的国家"
- **牛市追新股**："你从中赚到每一块钱时，都会赔掉两块钱，这还算是幸运的"——即使个别新股日后被证明是极好的购买对象，也是"若干年后无人问津时"的事
- **用当前业绩外推新股质量**：低等级新证券"看起来大体安全"是因为假定目前优良业绩延续无滑坡——承销商视这种假定为理所当然，"这种投资方法是不可靠的，有可能使投资者付出代价"

## Worked Example
**两个新股惨案**：
- Aetna维修公司：1961年每股$9发行 → 一度$15 → 次年$2.375 → 1964年$0.875
- "AAA企业"（标准普尔《股票指南》第一位）：发行价$14 → 迅速窜升$28 → 1971年初交易价**25美分**——"即使是这一价位也有高估之嫌，因为该公司已绝望地进入了破产程序"
- 1960–62年41种代表性新股样本：5种下跌90%以上、30种下跌50%以上，整体下跌约三分之二

## Key Takeaways
1. 积极型先做防御型的事，再谈超越——超越来自"不做什么"的清单
2. 二级债券只在大折价时买（≥30%折价起步），且必须用利息保障倍数检验
3. 为1%–2%额外利息承担本金风险是糟糕的商业决定
4. 外国债券：收益再高也买不了"法律救济权"——违约时无法主张权利
5. 新股发行的生命周期模型：质量递减+价格夸张=牛市见顶信号；底部时小盘股无人问津=机会
6. 抵御新股推销是聪明投资者的基本条件

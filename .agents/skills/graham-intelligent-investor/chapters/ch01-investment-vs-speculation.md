# 第1章 投资与投机：聪明投资者的预期收益

## Core Idea
全书的纲领章：严格区分"投资"与"投机"，为防御型与积极型两类投资者分别确立可实现的预期收益框架，并给出取得优于平均水平成果的唯二条件——策略必须**内在稳健**且**在华尔街不流行**。

## Frameworks Introduced

- **投资 vs 投机的定义**（1934《证券分析》原定义，38年后仍坚守）：
  - 投资业务 = 以深入分析为基础 + 确保本金的安全 + 获得适当的回报；不满足这三条的业务就是投机
  - 何时用：任何买入决策前先对照此定义自检；卖出不属于自己的股票（卖空）、抢购热门股、保证金交易皆属投机
  - How：对每笔操作问三个问题——有没有深入分析？本金是否安全？回报是否适当？

- **防御型 / 积极型（进取型）投资者二分法**：
  - 防御型：关心资金安全、不愿多花时间精力 → 只买长期盈利记录+财务状况强的重要公司股票，或指数化/基金化
  - 积极型：愿意投入时间研究、追求超额收益 → 先确保不亏得比防御型更糟，再谈超额
  - 何时用：投资前先确定自己是哪一类，据此选择策略；两者的分界是"愿意投入多少时间和精力"

- **债券/股票 25%–75% 程式投资（formula investing）**：
  - 股票占比最低不低于25%、最高不高于75%；最简单的做法是各占一半，随市场位置小幅（约5%）反向调整——"感觉市场危险时降到25%，吸引力日增时升到75%"
  - 如何执行：按预设规则机械反向操作，不依赖预测

- **激进型投资者取得超额收益的唯二条件**：
  1. 策略具有内在稳健性和成功希望
  2. 该策略在华尔街并不流行
  - 反例（必败三法）：市场交易（追涨杀跌）、短线择股（追逐当期/来年业绩）、长线择股（预测长期成长）

## Key Concepts
- **美元成本平均法（dollar-cost averaging）**：每月/每季投入等额资金买股，市场低迷时买到更多股份；是程式投资的典型应用
- **廉价证券（bargain issues）**：售价低于净流动资产（营运资本）的股票——1957年市场上有近200只，绝大多数最终有利可图且平均年收益远高于其他方式
- **特殊情况（special situations）**：交叉套利、资产清算、保护性对冲；行家以最低风险可获20%+年收益，但机会随竞争而衰减
- **自我膨胀**：1949–1969年道指上涨4倍，而公司利润与红利只增长约1倍——涨幅主要来自态度转变而非内在价值提升
- **预期收益基准（1972年初）**：防御型投资者股票部分 ≈ 3.5%股息 + 4%增值 = 7.5%税前；债券股票对半 ≈ 6%税前（1965年旧基准）→ 7.8%税前（1972年新基准）

## Mental Models
- **把市场报价当报价，不当指令**：买入时"市场先生"的报价只是参考（此处为伏笔，第8章展开）
- **用"反向一致"检验策略**：当媒体用"投资者"称呼所有交易者（包括做空的小投资者）时，说明术语已混乱，此时更要坚持定义
- **把投机单独隔离**：投机可以明智（当作消遣、资金极少、单开账户），但绝不可与投资混在一个账户、也绝不可在思想上混为一谈
- **收益递减法则适用于投资机会**：任何被证明有效的策略都会因追随者增多而失效（1949年买低卖高公式、特殊情况的例子）

## Anti-patterns
- **自以为在投资、实则投机**：用"投资"之名掩盖缺乏分析的行为——格雷厄姆说这是投机三宗罪之首
- **在缺乏知识与技能时把投机当正事**：投机只该是消遣，不是严肃事业
- **投机投入资金超出亏损承受能力**：任何抢购"热门"股、做保证金交易的人都在投机/赌博
- **追涨杀跌**：与罗思柴尔德"贱买贵卖"法则完全相反，是华尔街"遗祸无穷"的法则
- **按预测行动**：未来证券价格根本无法预测——1964年持有"现金等价物"胜过股票、而长期债券价格也大跌38%，均超出所有专家预期

## Worked Example
**1960–1970 指数对照**（说明无法预测哪一组更好）：
- 道琼斯工业指数：616 → 839 点，+36%
- 标准普尔500指数：58.11 → 92.15，+58%
- 结论：事后看S&P500明显更优，但事前无人敢断言"杂七杂八"的指数会跑赢"30巨头"——价格变化（相对或绝对）几乎无法可靠预测。

**1948 vs 1970 公众态度反转**：1948年90%+被访者不赞成买普通股（一半人理由："像赌博，不安全"），而当时股价正处历史性买入良机；1970年"鲁莽投资者"竞相抢购时，股价已被推至危险高位。→ 公众态度是最差的反向指标之一。

## Key Takeaways
1. 每次买入前自检三问：深入分析了吗？本金安全吗？回报适当吗？——不满足就是投机
2. 防御型投资者：股票占25%–75%，简单对半开，随市场情绪反向小幅调整；不指望超越平均
3. 想要超越平均，策略必须同时满足"内在稳健"和"在华尔街不流行"——热门方法必然无效
4. 投机资金与投资资金物理隔离（分账户），投入"越少越好"
5. 别买新股和"热门"股追求快速致富——长远几乎必然适得其反
6. 美元成本平均法是防御型投资者最省心且有效的执行工具

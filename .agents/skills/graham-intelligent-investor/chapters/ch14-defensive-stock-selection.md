# 第14章 防御型投资者的股票选择

## Core Idea
给防御型投资者一整套**可以照抄的选股规则**：七项定量标准（规模、财务、股息、利润、增长、市盈率、价格/资产）——用1970年底的道琼斯30家逐一检验，结果只有5家全部达标；然后给出两条出路：**公用事业股**（放宽流动比、几乎全部达标）和**放弃"选最优"的执念**（分散化优于个股选择）。全章的哲学核心：市场估价有双重基础（已知事实+未来预期），对应预测法（定性）与保护法（定量）两种分析——"我们始终致力于定量法……不愿以未来的前景和承诺，来补偿眼下价值的不足"。

## Frameworks Introduced

- **防御型投资者的股票选择（两种组合方法）**：
  - 方法一：**道指式组合**——将30种道指成分股等额买入（"道指900点时，30种股票各买10股大约需要$16,000"）——无需分析技巧
  - 方法二：**定量检验组合**——用7项标准筛选后购买达标股票
- **七项选择标准（防御型）**：
  1. **相当的规模**：工业企业销售额≥$1亿（制造业），公用事业总资产≥$5,000万
  2. **足够强劲的财务状况**：流动比≥2:1（流动资产/流动负债）；长期债务不超过营运资本（公用事业：债务≤2倍股本）
  3. **盈利稳定**：过去10年每年都有利润
  4. **股息记录**：至少20年连续支付
  5. **利润增长**：10年内每股利润增长≥1/3（3年平均比较）
  6. **市盈率≤15倍**（3年平均利润）——据此整个组合的平均PE约12–13倍
  7. **股价≤净资产价值的1.5倍**；且PE×P/B≤22.5（两者相互调节）
  - **底线建议**：组合的盈利收益率（PE的倒数）应≥当期高等级债券利率——1970年底道指PE约13.3倍，盈利收益率约7.5%，恰好等于AA级债券——"在价格比较合适的时候，人们可以用股息和利息收入来证明持有一组普通股是合理的"
- **预测法（定性法）vs 保护法（定量法）**：
  - 预测法：努力准确预测未来几年利润增长——航空股是反面教材（多年看好，1946年后表现经常令人失望）
  - 保护法：关注研究时的价格——"确保自己获得的现值足够大于市场价格——这一差额可以吸纳未来不利因素造成的影响"——只需相信企业持续经营
  - 定量法是"把证券分析中债券和优先股投资选择的方法扩展到普通股领域而产生的"

## Key Concepts
- **市场估价的双重基础**：当期价格反映"已知事实"与"未来预期"两类因素——每类因素对应一种分析方法；"如果所有分析师都认为某股票优于其他股票，该股票价格将迅速上升，从而抵消它以前所具有的各种优势"
- **为什么100位分析师选不出"最好的5只股票"**：每种优质股票的当期价格都已充分反映其财务记录与前景预期——任何"优于他人"的观点都来自个人偏好、预期权重差异——**"最优"股票的选择本质上是有极大争议的问题**
- **达标股票的稀缺性**：道指30家全部满足7项标准的只有5家（American Can、AT&T、Anaconda、Swift、Woolworth）；1970年底标准普尔《股票指南》中约100种——"投资者可以满意地选择到自己的股票"
- **1960→1970的流动比恶化**：道指成分股中流动比不达标的公司从2家增至12家——"低价格和高利率对资本和融资的影响"
- **公用事业的例外处理**：去掉流动比标准（营运资本因素本身无需关注——增长所需后续融资可通过出售债券和股票获得），改为要求股本与债务比适当；排除燃气管道股（债券发行规模太大）
- **金融类企业**：银行、保险、储贷协会、信贷公司、抵押贷款公司、投资公司——实物资产少、短期负债多于股本——"财务的稳健性对金融类企业更为重要"，因此产生各种监管；只能沿用同样的PE与价格/账面值标准，无法给出更好的建议
- **出售后纳税 vs 后悔**：组合需要"不断加以调整，尤其是当所购证券的价格明显上涨过度，并且可以用定价更为合理的证券替代时"——"出售后去纳税，比留在手中等待后悔要更好"
- **技术因素的折中**：技术进步对企业长期结果影响越来越重要，"投资者必须在忽视与过分重视之间找到一个折衷点"

## Mental Models
- **标准"保证"的是价值，不是市场表现**："没有哪一种系统或方法，能够保证获得最好的市场结果。我们所要求的标准，只能'保证'证券组合购买者得到他应该得到的价值"
- **分散化即对选择雄心的否定**："为人们普遍接受的分散化观点，至少在一定程度上否认了选择性方面所存在的雄心。如果能够正确地挑选出最佳的股票，那么分散化就只能带来不利后果"
- **偏好无害论**：在四大原则范围内，个人偏好有相当大的自由空间——"从最不利的角度来看，纵容这种偏好应该不会有害处，除此之外，它还有可能使结果得到改善"
- **未来只能被"保护"而不能被"预测"**：分析师都关注未来（工作好坏取决于未来结果），但对待未来的方式只有两种——预测它，或者保护自己免受其害；格雷厄姆选择后者

## Anti-patterns
- **把"某一整个类别"一棍子打死**："向人们建议购买某一整个类别的证券的做法，通常都是不稳定的，同样我们也不赞成排除整个类别证券的做法"——铁路股表14-6显示"总体上这一类股票经常能提供巨额的获利机会"（尽管大幅上涨本身不太合理）
- **无充分理由持有铁路股**：激烈竞争+严格管制（小汽车/公交车/航空抢旅客、卡车抢货运）——过去50年一半铁路里程处于破产或接管状态；宾州中央1970年破产，此前1–2年股价接近历史最高、**已连续支付股息120多年**
- **低估金融企业稳健性的重要性**：实物资产少+短期负债多→财务稳健是生命线，监管因此存在
- **持有价格明显过度的证券不动**：即使要付资本利得税也应更换——"出售后去纳税，比留在手中等待后悔要更好"

## Worked Example
**1970年底道指30家的"体检"（表14-1/14-2/14-3）**：
- 以道指整体计：年终股价/3年平均盈利 = 839:55.5 ≈ **15:1**（恰好是建议上限）；股价/净资产 = 839:562，恰在1.5:1限额内；10年增长率77%（约每年6%），但有5家企业增长未达1/3
- 逐家套用7项标准：仅5家（American Can、AT&T、Anaconda、Swift、Woolworth）全部达标——组合数据"大大好于整个道琼斯的情况，除了过去的增长率之外"（表14-3：市盈率10.5–14.4倍、股价/账面值112%–148%）
- 1970年12月→1972年初，这5家市场表现反而亚于道指整体——"再一次证明了：没有哪种系统或方法能保证获得最好的市场结果"
- 公用事业出路（表14-4/14-5）：1972年初30只公用事业股（道指公用事业15家+另组15家）几乎全部满足业绩和价格要求——增长记录几乎与工业一样出色、年度波动更小、股息回报率高得多

## Key Takeaways
1. 七项标准可照抄执行：规模/流动比2:1/10年无赤字/20年股息/增长1/3/PE≤15/价格≤1.5倍净资产（或PE×P/B≤22.5）
2. 达标股票稀缺：道指30家中仅5家——但这5家价值有据，"恰好是投资者应得的"
3. 底线：组合盈利收益率≥高等级债券利率（1970年两者恰好相等）
4. 公用事业是防御型的优选领域（放宽流动比、严查股本/债务比）
5. 两种分析法中，格雷厄姆立场明确：定量/保护法，不用未来前景补偿当下价值不足
6. 防御型投资者不做"最优选择"——分散化优先，偏好只在原则范围内自由
7. 价格上涨过度就换仓，付税比后悔好

# 导言：本书的目的

## Core Idea
全书的"使用手册"：明确读者定位（写给投资者，不是投机者）、本书宗旨（**避免严重错误 + 建立令自己安心放心的投资策略**）、方法（重投资原理与投资者态度，而非证券分析技巧）与资料来源（金融市场历史——"忘记过去的人，必将重蹈覆辙"）。并给出贯穿全书的第一项要求：**只买价格不高于有形资产价值太多的股票**。本章还预告第4版（1972年）修订的时代背景：债券收益率史无前例地超过股息、1969–70年龙头股大跌35%、通货膨胀与"综合企业"投机浪潮。

## Frameworks Introduced

- **本书宗旨框架（三大支柱）**：
  1. 指导读者避免陷入严重的错误；
  2. 建立一套令其感到安全放心的投资策略；
  3. 通过说理、举例和劝告，帮助读者形成"恰当的心智和情绪"。
  - 何时用：任何"读这本书到底要我做什么"的疑问——防御、安心、情绪，三者缺一不可

- **美元成本平均法（dollar-cost averaging，定期定额策略）**：
  - 每月/每季投入等额资金购买优质股，不择时
  - 何时用：防御型投资者买入股票的执行方式；"不管市场如何，每月定期买入优质股"
  - 证据：1929–1948年按拉斯科布方法投资道指30样本股，1949年初得8,500美元（远低于其承诺的80,000美元），但年复合收益率仍达8%以上——且期间道指从300点跌到177点；结论：**定期定额被证明有效，但任何乐观预测和保证都不可信**

- **对技术分析/追随市场方法的否定**：
  - 几乎所有"技术方法"都遵循"因股市上涨而买进，因下跌而卖出"——与其他商业领域的合理经营原则背道而驰
  - 50余年市场经验中"从来没有发现过一个依据这种'追随市场'的方法而长期获利的投资者"——"我们可以大胆地认为，此种方法无疑是荒谬的，虽然它仍然十分流行"（以道氏理论为例）

- **两类投资者的正式定义（全书二分法的源头）**：
  - **防御型（被动型）**：首要目的是避免重大错误或损失；其次是不必付出太多努力、承受太大烦恼去经常性地作投资决策
  - **进取型（积极型/激进型）**：愿意为挑选合理且更具吸引力的股票付出时间和精力，以获取超出平均水准的回报
  - 格雷厄姆的诚实保留："在现今的形势下，我们对积极的投资者是否能获得相当的超额收益，确实颇感怀疑。但明年或许多年以后，情况会有所不同。"

- **成长股方法的两条教训**（以1949年版自引和1970年代实绩佐证）：
  1. **某一行业显而易见的业务增长前景，并不一定会为投资者带来显而易见的利润**——航空业：1970年运输量创新高，却为股东带来2亿美元亏损（1945、1961年也亏损），1969–70年股价跌幅超出市场整体水平；
  2. **即使是专家，也没有可靠的方法挑出前景光明的行业中最有前途的公司**——基金对IBM投入不到3%（股价过高、未来增速不确定），贡献不了多少整体业绩；对IBM以外大多数计算机公司的投资"似乎并不赚钱"。

- **"它价值几何？"——度量（量化）观念**：
  - 对99%的股票：某些价位相当便宜、值得购买；另一些价位过于昂贵、应当抛出
  - 把"所付出的与所得到的进行比较"是投资方面的一种宝贵特征；"购买股票要像购买食品杂货一样，而不要像买香水一样"
  - 参照系：1970年6月高级公用事业公司债券收益率9.4%（后降至7.3%）——在问"为什么给出其他答案"之前，先问这个数字

- **第一项要求：价格不高于有形资产价值太多**（"有些过时"但必须遵守）：
  - 实用理由：成长性突出企业的买家会过分受制于股市的变化和波动
  - 心理理由：以接近净资产价值买进的投资者，总可以把自己视为稳健和成长企业的权益拥有者，"而不管股票市场对此有什么不同的看法"

- **投资艺术的悖论**：
  - 普通投资者只需很小的努力和能力，就能取得"可靠（即便并不壮观）的成果"；但想提高这成果，需要大量努力和非同小可的智慧
  - "只想为投资计划付出一点额外的知识和智慧，却想取得大大超出一般的投资成果，你很可能会发现自己陷入一种更糟糕的境地"
  - 证据：大多数投资基金不能击败市场（尽管有经验丰富的专家）；证券经纪公司精心预测的结果"还不如简单的掷硬币方法可靠"

- **稳健原则不变，应用随环境调整**：
  - "稳健投资的基本原理是不会随着年代的更替而改变的，但这些原理的应用，则必须随着金融机制和金融环境所发生的重大变化而作出相应的调整"
  - 第4版修订背景（1965年版以来）：①高级别债券利率空前上涨（1972年最高级债券7.19% vs 工业股股息2.76%；1949年恰好相反：2.66% vs 6.82%）→ 考虑将债券投资比例扩大，直至两种工具收益回归合理比率；②1970年5月龙头股跌35%（近30年最大跌幅）；③批发零售物价持续上涨；④"综合性"企业、特许经营等新模式快速发展（含欺诈手段：存信股、股票期权、误导性名称）；⑤美国最大铁路公司的破产、大公司债务过多；⑥投资基金追逐"业绩"的令人担心的后果（基金大量介入高度投机且价值明显高估的股票）

## Key Concepts
- **桑塔耶纳告诫**："忘记过去的人，必将重蹈覆辙"——本书大量篇幅讲金融市场历史的原因
- **防御型/进取型**：全书分类的正式定义处（对应SKILL框架F1）
- **美元成本平均法**：定期定额买入优质股的执行策略
- **有形资产价值**：第一项要求的价格锚——价格不高于其太多
- **"它价值几何"**：买入前必问的度量问题
- **投资者最大的敌人是自己**："亲爱的投资者，问题不在我们的命运，也无关乎我们的股票，而在于我们自己。"
- **本书范围**：只针对投入交易（流通）证券的资金——债券和股票；储蓄存款、人寿保险、年金、不动产抵押等不讨论；"现在"指1971年底或1972年初

## Mental Models
- **把热情当华尔街的毒药**："热情在其他行业是一项必不可少的品质，但在华尔街却总会招致灾难"——这一警告不只适用于新手
- **把市场波动当背景噪音**：1970年低点632点→1971年高点951点→定稿时797点——"我们一直没有让这种波动影响我们对稳健投资策略的总体看法"
- **用历史反例校准承诺**：拉斯科布的"每个人都应该成为富人"（1929年《女士之家杂志》）——乐观预测与保证几乎都不可信
- **把自己当企业权益拥有者**：以接近净资产买进的人"总可以把自己视为稳健和成长企业的权益拥有者，而不管股票市场对此有什么不同的看法"
- **先问基准收益率**：做任何股票决策前，先问"债券收益率是多少"——1970年6月的答案是9.4%

## Anti-patterns
- **凭乐观预测与保证投资**：拉斯科布式承诺——"任何乐观的预测和保证，都是多么的不可信"
- **追随市场（技术方法）**：因上涨买进、因下跌卖出——与合理经营原则背道而驰，50年未见长期获利者
- **追逐热门成长行业中的热门公司**：航空股、多数计算机股——行业增长≠股东利润
- **把股票当香水买**：买股票不问"它价值几何"——近年投资损失的主因
- **超出自我检验能力去做决策**：为可观回报而尝试缺乏大量自我检验的决策，"不要做"
- **误把本书当致富捷径**：本书不是"如何成为百万富翁"的书——"在华尔街，就像在其他任何地方一样，并没有一条可靠和简单的致富之路"

## Worked Example
**拉斯科布承诺 vs 现实（1929–1948）**：每月储蓄15美元、投资优质普通股、红利再投资，20年后累计投入3,600美元应变成80,000美元。按道琼斯工业平均数的30只样本股实际操作，1949年初只有8,500美元——承诺缩水90%；但折算年复合收益率仍达8%以上，且期间道指从300点跌至177点。→ 一个案例同时证明：美元成本平均法有效、乐观承诺不可信。

**航空业 vs IBM（1960s–70s）**：航空业运输量连年创新高（增速甚至高于计算机行业），但技术问题+产能过度扩张使利润极不稳定——1970年亏损2亿美元，1969–70年股价超市场跌幅；基金最爱的行业反成亏损重灾区。IBM业绩极佳，但基金因股价过高、增速不确定而投入不到3%，对整体业绩贡献寥寥；IBM以外大多数计算机公司投资并不赚钱。→ 行业增长前景既不保证利润、也不可被可靠挑选。

## Key Takeaways
1. 本书三件事：避免严重错误、建立安心策略、塑造恰当情绪——情绪适合投资的"普通人"比知识多而情绪不当的人更能赚钱、留住钱
2. 买入前先问"它价值几何"，把所付出与所得到进行比较——像买食品杂货，不像买香水
3. 第一项要求：价格不高于有形资产价值太多——实用与心理双重理由
4. 防御型投资者的执行工具：美元成本平均法（定期定额买优质股）——但警惕任何乐观承诺
5. 想超越平均：需要大量努力和非同小可的智慧，失败比率相当高——基金、券商预测都不如掷硬币
6. 稳健原则不变，应用随环境调整；市场波动是背景噪音，不是策略指令

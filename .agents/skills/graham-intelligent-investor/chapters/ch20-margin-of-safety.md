# 第20章 作为投资中心思想的"安全边际"

## Core Idea
全书的总结章："当我们需要总结出稳健投资的秘密时，可以用**安全边际**这一座右铭来代表。这是一条主线，它贯穿于前面所有关于投资策略的论述之中。"安全边际的功能是**使投资者不必对未来做出准确的预测**——"如果安全边际较大，那么就足以保证未来的利润不会大大低于过去的情况，从而使得投资者不会因为时间的变化而遭遇风险"。章末以四条商业准则结束全书：**"知道自己在干什么"、"不要让其他任何人来管理你的业务"、"没有可靠的计算就不要涉足"、"有勇气相信自己的知识和经验"**——"获得令人满意的投资结果，比大多数人想象的要简单；获得非常好的结果，比人们所想象的要难。"

## Frameworks Introduced

- **安全边际的三种形态**：
  1. **债券/优先股（利润保障形态）**：铁路债券税前利润≥总固定费用5倍以上且连续多年——"过去能够使利润超出利息要求的能力构成了一种安全边际——一旦公司未来的净收益下降，它可以防止投资者遭受损失或失败"；也可用"利润还可下降多少百分比"表达——根本思想一样
  2. **债券/优先股（价值缓冲形态）**：企业总价值 vs 债务规模——$1,000万债务、$3,000万公允价值 → 债券持有人亏损前企业价值有三分之二下降空间；"这部分高于债务的额外价值，或'缓冲价值'"可用次级股份的平均市场价大致计算——"平均股价一般与平均盈利能力相关联，因此'企业价值'超出债务的差额和利润超出费用的差额，在大多数情况下都会带来同样的结果"
  3. **普通股（盈利能力形态）**：预期的盈利能力大大高于债券利率——9%盈利能力 vs 4%利率 → 每年5%归自己；10年内高于债券利率的累积盈利能力一般达到购买价的50%——"这一数字足以提供一种非常可靠的安全边际"；20种以上股票分散化后"获得有利结果的概率将会很大"
- **1972年的困境（本书时的应用）**：12倍PE = 8.33%利润率、4%股息、4.33%再投资——10年内超出债券利息的部分"太小，而且还不到应有的安全边际"——"我们认为现在面临着实际的风险，即使是由稳妥的普通股构成的分散化组合"——但持有固定应付债权面对美元持续贬值是更大的风险——"投资者最好能够认识到，以前的低风险和高收益组合已不复存在（并尽量把这作为一种理念）"
- **投资与投机的区分标准**：真正的投资必须有真正的安全边际作为保障——"真正的安全边际可以通过数据、有说服力的推论以及一些实际的经历而得到证明"；投机者的"胜算"是主观判断（时机/技能/顾问/系统），"不能得到任何一组有利证据或任何一种推论的支持"
- **非传统投资的范围**：二类公司被低估的普通股（**股价≤评估价值的三分之二**时购买）、售价低廉的中等级别债券和优先股——"足够低的价格能够使得质量等级一般的证券变成稳健的投资机会"（购买者了解信息、有经验、适当分散化）
- **四条商业准则（全书结论）**：
  1. "知道自己在干什么，即通晓自己的业务"——不要试图通过证券获得"商业利润"（超过正常利息和股息收益的回报），除非你足够了解证券的价值
  2. "不要让其他任何人来管理你的业务，除非你能够足够细致地监控并理解他的行为；或者是你内心中有很强的理由相信他的品格和能力"
  3. "如果没有可靠的计算表明某项业务获得合理利润的机会较大就不要涉足这项业务。尤其是要远离那些利益不大，亏损却很严重的业务"——利润应建立在计算结果上，而非乐观情绪
  4. "有勇气相信自己的知识和经验……如果你的数据和推理是正确的，你的行为就是正确的"——"一旦获得了足够的知识并得出了经过验证的判断之后，勇气就成为最重要的品德"

## Key Concepts
- **分散化与安全边际的逻辑联系**："个别证券还是有可能出现不好的结果。因为安全边际只能保证盈利的机会大于亏损的机会，并不能保证不会出现亏损。但是，当所购买的具有安全边际的证券种类越来越多时，总体利润超过总体亏损的可能性就越来越大。这就是保险业务的基本思想"
- **轮盘赌演示（正负安全边际）**：单数下注1美元赢35美元、输赢比37:1 → 安全边际为负数 → 分散化是愚蠢行为；若赢39美元 → 有"虽然不大但却很重要的安全边际" → 下注次数越多取胜机会越大；每次对所有数下注必然每转一次赚2美元——"这两个例子实际上描述了轮盘赌的玩家与店老板之间的相对地位"
- **成长股的悖论**：成长股购买者"以预期利润取代了以往的利润记录"——"只要对未来的计算是稳妥的，而且相对于购买价而言存在着令人满意的安全边际"，其分析方法得出的安全边际同样可靠；但广受欢迎时市场会使价格"不能得到稳妥预测的未来利润的恰当保护"——**谨慎投资的基本法则："所有估算出来的结果，如果与过去的情况不同的话，都必须至少稍稍偏保守一些"**——安全边际"总是依赖于所支付的价格"
- **廉价证券的定义**："证券的市场价格高于证券的评估价格的差额。这一差额反映了证券的安全边际。它可以吸纳计算失误或情况较差所造成的影响"——被低估的证券大多来自"未来既没有明显的吸引力，也不是明显没有希望"的企业
- **"有利条件下的投资"**：投资者主要亏损的来源——"证券购买者把当期较高的利润当成了'盈利能力'，并且认为业务兴旺就等同于安全边际"——利息费用和优先股股息的保障"必须经过多年的检验——最好是包含了像1970～1971年那样经济较差的时期"——不利条件下"没有真正意义上的安全边际来保证他度过这一困境"
- **1920年代房地产债券的反转**：数十亿美元按面值出售、被广泛认为是稳健投资——安全边际（超出债务价值的部分）很小、实际投机性很高——大萧条中价格崩盘（有时跌到面值10%以下）——同一批顾问又拒绝它们；但事实上约值面值4-5倍的"大笔投机利润"——"这部分'投机'利润，是购买者不寻常的精明投资所带来的回报……经过细心的分析可以看到，高于价格的这部分价值提供了很大的安全边际"
- **特殊情况也属于投资**：证券购买"总是取决于透彻的分析所做出的预测：将来所得的结果要大于现在支付的价格"——风险因素已考虑在内，可被分散化总体结果吸纳
- **极端推论（权证）**：价格处于历史最低水平时购买普通股期权所代表的无形资产价值——"即使这种没有吸引力的证券也具有了安全边际"（Hallingby, 1947）

## Mental Models
- **"这，也将成为过去"**：古老传说中智者把人类历史归纳为一句话——安全边际是与之对应的投资座右铭
- **安全边际=免于预测**："本质上，这里的安全边际的作用是使投资者不必对未来做出准确的预测"
- **把投资当生意**："每一种公司证券都应该首先被看成是针对特定企业的一部分所有权或债权"——"如果某人一心想通过证券的买卖来获利，那么他是在从事自己的风险业务。如果他想有成功的机会，就必须按照公认的商业准则去行事"——企业家在业务中遵循稳健原则，却在华尔街违背所有稳健原则，"我们惊讶地发现"这一点
- **盈利再投资与价值的联系**："利润再投资给公司带来的盈余增长与公司价值的增长之间必然有着密切的联系"（但市场更看重股息分配——股息是"实实在在的钱"）

## Anti-patterns
- **把业务兴旺当安全边际**：主要亏损来自经济有利时期购买的劣质证券——"质量较差的债券和优先股才能大约按平价出售给公众"，不知名公司普通股"凭借两三年快速增长的实力，按大大高于其有形投资的价格发行出去"
- **在繁荣期用当期利润验证安全性**：保障"必须经过多年的检验——最好是包含了经济较差的时期"
- **集中购买价格很高的股票**或购买不具代表性的普通股（盈利能力下降风险大于一般水平）
- **依赖主观胜算**：时机判断/技能优越感/顾问或系统的可靠性——"我们十分怀疑，根据自己对市场走势的判断投入资金的人，是否能得到真正意义上的安全边际的保护"
- **在成长股上简单分散化**：市场平均价格太高无法提供适当安全边际时，"在这一领域简单地使用分散化购买的方法是不会获得令人满意的结果的"——需要"相当程度的预见性和判断力"

## Worked Example
**普通股安全边际的算术（前几版的经典示例）**：
- 股票盈利能力9%、债券利率4% → 股票购买者平均每年有5%利润属于自己
- 10年内高于债券利率的累积盈利能力 ≈ 购买价的50% → 非常可靠的安全边际
- 20种以上股票分散化 → "在'比较正常的情况下'，获得有利结果的概率将会很大"
- 这就是"投资于有代表性的普通股的策略并不要求有很强的分析和预见能力就可以取得成功"的原因——**"如果按几年的市场平均水平买股票，那么，所支付的价格应该能够确保获得足够的安全边际"**

## Key Takeaways
1. 安全边际=使投资者不必预测未来——利润保障/价值缓冲/盈利能力三种形态
2. 债券标准：税前5倍保障（铁路）；价值缓冲：总价值≥3倍债务
3. 普通股：10年累积盈利能力超出债券利率≈购买价50%——分散化后概率很大
4. 1972年现实：8.33%利润率+4%股息不足以提供应有安全边际——低风险高收益时代已过
5. 主要亏损来自"有利条件下的投资"——当期高利润≠盈利能力，业务兴旺≠安全边际
6. 成长股可行，但市场平均价常不给保护——估算必须保守，安全边际取决于价格
7. 低价使一般质量的证券变成稳健投资（评估价值2/3以下购买）
8. 四条商业准则：通晓业务/亲自监控/可靠计算/相信自己的判断——"获得令人满意的投资结果比想象的要简单；获得非常好的结果比想象的要难"

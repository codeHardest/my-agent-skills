# 第9章 基金投资

## Core Idea
基金行业总体有功——它培养了储蓄投资习惯、让无数人免受新股推销员的"更危险诡计"——但**基金无法保证优于平均水平**：整个行业就是市场本身（基金经理掌管如此大规模的股票，"股市平均水平的走向完全可以决定基金的总体结果"）。防御型投资者应选**折价销售的封闭式基金**（而非支付9%费用的开放式基金），并远离"业绩基金"。

## Frameworks Introduced

- **封闭式 vs 开放式基金的选择算术**：
  - 开放式（共同基金）：按净资产价值赎回，向公众出售大多按高于净资产约9%的固定费用销售（销售佣金）
  - 封闭式：股份固定，像普通股一样随市场波动，**大多数一直按低于资产价值的折扣价购买**（平均折扣随时间变化，1961–70年间约-3%到-14%）
  - 决策规则："按资产价值10%–15%折扣购买一组封闭式基金股份，而不要按高于资产价值9%的费用去购买开放式基金公司的股份"——若两类基金股息和资产价值变化相同，封闭式投资者的收入大约多五分之一
  - **折扣弹性检验**：投资者A按109%买开放式、B按85%+1.5%佣金买封闭式；4年后两类股份资产价值都涨30%且终值相同——A总回报30%-9%=21%（约投资额的19%）；B要与A持平可容忍折扣扩大到**27%**（12个百分点的恶化，约两倍）——"这么大幅度的不利变化极少发生，而且即使发生的话，也没有出现在封闭式基金的历史上"
- **"业绩基金"（performance funds）的剖析**：
  - 特征：年轻管理人（30–40多岁，"直接的金融经历仅限于1948–1968年持续的牛市期"）；把"好的投资"定义为"随后几个月内市场价格有可能大幅上升的股票"；大量资金流入股价与资产或利润记录完全不相称的新企业
  - 曼哈顿基金：1965年末设立、启动资本$2.47亿；1967年总收益38.6%（标普仅11%）→ 1969年底组合中两家公司随后6个月申请破产、第三家遭债权人诉讼；1970年-36.9%（标普-8.3%）——"创始人兼管理者"以资产不到100万美元的管理公司换取某大企业2000万美元股份："毫无疑问，这是有史以来'管理者'和'被管理者'的结果之间所产生的最大的一次不平等"
  - 《货币经理》（Money Managers）中的12位"领军人物"：1966年不错、1967年非常突出、1968年尚可但个体分化、1969年全部亏损（仅1人勉强好于标普）、1970年更差
  - 1967年表现最佳的10只基金（收益84%–301%）：仅4只的4年总体业绩好于标普、2只在1968–70年间超过标普；平均规模约$6,000万——**"规模较小是持续获得优异结果的必要因素"**

## Key Concepts
- **基金业的真实贡献**：储蓄投资的好习惯、免受股市错误投资的巨大损失、收益与普通股总体回报相当——"过去10年内，专门投资于基金股份的人所获得的收益，要优于直接购买普通股的人"（因为一般人的实际选择是"基金 vs 二、三等新股推销者"）
- **前十家基金整体业绩（1961–70）**：与标普综合指数"没有明显差别"，优于道指30巨头；1961–65稍低于标普、1966–70稍高于标普；**单个基金结果之间差别非常大**
- **选基金的历史业绩标准**：可以适当比较至少5年业绩（只要数据没有代表整个市场大幅向上趋势）——市场大涨时"十分有利的结果可能来自于非正统的方式"，只反映"基金经理正在从事过度的投机风险，并且暂时获得了过高的收益"
- **管理稳妥的大基金的极限**："几年之内至多能获得稍微高于平均水平的结果"；持续10年+跑赢市场的是"非常特殊的例子"：集中于专门领域、资本利用自我限制、不向公众大量出售
- **平衡基金**：债券资产占比25%–59%（平均40%），1970年平均回报率仅资产价值的3.9%（发行价的3.6%）——普通投资者应**直接从事债券类投资**（储蓄债券、A级以上公司债、免税债券），不必通过共同基金
- **存信股（letter stock）**：按大大低于市场报价买入、不受公开出售限制，随后按完整市场价值计入财务报告"以显示出虚幻的诱人利润"

## Mental Models
- **机构即市场**：基金、银行信托、投资顾问管理的普通股规模足以"决定股市平均水平的走向"——行业整体不可能跑赢自己
- **业绩神话的世代循环**：1926–29的骗局被SEC禁止后，"在华尔街的许多角落，它们已被新的花样和把戏所取代，最终这些会带来非常相似的结果"——法国谚语"物极必反"；"人们很难指望投机冲动会被永久性废除"
- **用"异常受欢迎的幻觉"当过滤器**：麦奇《特别受欢迎的幻觉以及大众的疯狂》——了解历史上大众如何相信荒谬之事（炼金、迅速致富），"尽可能远离它们"
- **管理人与股东的利益缺口**：以他人之钱承诺创造奇迹，"他们一般能够暂时做到这一点（或者说，至少看起来是做到了），但是，最终他们将给公众带来损失"

## Anti-patterns
- **按9%费用买开放式基金**：销售费用按包含费用的售价百分比表示，"使这一百分比看上去比使用净资产价值算出来的要低一些——我们认为，这种销售伎俩有损于这个行业的声望"
- **追逐"业绩基金"**：1967年收益84%–301%的10只基金，4年后仅4只跑赢标普；"暂时获得惊人的虚幻利润，随后必然遭遇灾难性的损失"
- **以基金替代债券投资**：平衡基金债券部分的回报（3.9%）远逊于直接持有储蓄债券/高等级公司债/免税债券
- **购买溢价销售的封闭式基金**：溢价公司（3家外国投资公司——1970年底售价分别只有最高价的1/4、1/3、1/2）的10年平均回报虽好于贴现基金，但最后5年"情况正好相反"——溢价难以用业绩解释
- **把明星基金经理当永久优势**：业绩优秀者"大多是30几岁和40几岁的年轻人，其直接的金融经历仅限于持续牛市期"——从未经历过熊市的成功不是成功

## Worked Example
**封闭式 vs 开放式基金的数字对比**：
- 投资者A：按109%购买开放式基金；4年后资产价值涨30%，按100%兑现 → 总回报30%−9% = 21%（约投资额的19%）
- 投资者B：按85%+1.5%佣金购买封闭式基金；同样资产涨30% → 与A持平所需的折扣扩大容忍度 = 27%（12个百分点）——历史从未出现
- 结论：投资业绩大致相同时，按折扣价买封闭式基金的总体回报"极有可能要高于"开放式基金

## Key Takeaways
1. 基金行业整体不输指数（也不赢指数）——它存在的理由是保护储蓄者免遭更糟糕的选择
2. 选基金：至少5年业绩比较，且警惕大涨年份的非正统来源
3. 买封闭式基金按10%–15%折扣，别付9%费用买开放式
4. 业绩基金=投机风险暂时兑现——1967年的明星们随后集体亏损
5. 债券部分自己买（储蓄债券/高等级债券），基金管不了这个
6. 规模是业绩的必要条件（越小越能持续优异）——大基金至多稍微跑赢

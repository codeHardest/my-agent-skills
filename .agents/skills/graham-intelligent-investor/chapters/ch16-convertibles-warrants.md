# 第16章 可转换证券及认股权证

## Core Idea
两种"两全其美"的金融发明都经不起检验。可转换证券的宣传（投资者拿到保护+上涨机会，发行者拿到低成本资金）"一定有所夸大——你不可能仅仅通过一种巧妙的手段使交易双方都获得好处"：统计数据表明**可转换权的获得，经常（或许通常情况下）会以丧失证券实际的投资质量为代价**，牛市后期发行的可转换证券尤其如此。认股权证则被格雷厄姆直接定性为"近似于一种欺诈行为"——"它们凭空捏造出了大量的美元'价值'……应该受到法律的禁止，或者至少应该被严格限制"。

## Frameworks Introduced

- **可转换证券的购买检验（排除法）**：
  - 对**新发行**的可转换债券"一般都是持怀疑态度的"——购买之前要三思
  - 理想条件（极少满足）：基础非常牢固的可转换债券 + 可以按稍高于当期市场的价格转换成"本身具有吸引力的"普通股
  - 关键启示："与新发行的债券相比，更有可能在**已发行的债券**中找到这种机会"——"如果一种新的债券真的实力很强，那它不太可能拥有好的转换权"
- **可转换证券的持有策略（赎回两难）**：
  - 问题：小幅上涨后卖掉，还是持有等更大涨幅？被赎回时，卖掉还是转换成普通股继续持有？
  - 计算示例：$100面值6%债券、可按$25转换为40股；股价$30→债券价值≥$120、售价$125——卖掉赚25%还是持有？"价格高于$125后，其头寸的投机性会太大"
  - 僵局分析：过早出售→股价继续涨→心疼；下次持到$140不卖→崩盘到$80——"他又犯了一次错误"
  - "25%–30%利润出售"的严格策略只是**利润上限**且只对表现良好的债券有效——很多可转换债券缺乏适当的标的证券、在牛市后期发行，永远到不了$125
- **稀释的算术（权证/转换权的正确处理）**：
  - 每股利润计算**没有**（或一直没有）对权证影响给予适当考虑——"夸大了利润与公司资本的市场价值之间的实际关系"
  - 正确方法：**把权证的市场等值额加入普通股资本**，从而增加每股的"实际"市场价——National General（表16-4）：3种权证市值$9,400万 → 每股权证价值$18.80；普通股$24.50 → **调整后$43.30**；公司算的市盈率10.5倍/15.3倍 vs 正确算法18.5倍/27.2倍（扣除特殊项目后甚至48.1倍 vs 18.4倍）

## Key Concepts
- **换取转换权的代价**："投资者通常要在证券的质量或收益（或同时在两方面）做出一些重要的让步"——福特金融1971年同发两种债券：20年期不可转换7.5% vs 25年期次级4.5%+按$68.5转换——"为了获得转换权，债券购买者放弃了40%的收入，并接受了次级债权人的地位"
- **1946年（牛市最后一年）可转换优先股的数据**：平均跌幅约30% vs 一般优先股约9%；1967.12–1970.12可转换优先股平均跌幅大于普通股整体（-5%）；表16-2（各20种样本）：一般优先股（A级及以上）平均跌10%、A级以下17%、可转换优先股29%、上市普通股33%；20种可转换优先股中只有1种上涨、14种严重下跌
- **稳健性只能用下跌期检验**：1950–1968长牛市里可转换债券总体不错——但那只是普通股普涨；"可转换债券投资的稳健性，只能通过它们在股市下跌时的业绩来判断——事实证明，这种情况下它们的总体结果总是令人失望的"
- **"永远不要把可转换债券进行转换"**：一旦转换就丧失了"获取利息的同时还有可能获得可观利润"的战略组合——"这有可能使你从投资者转变为投机者，而且这时常是发生在不利的情况下（因为股价已经经历大幅上涨）"——Eversharp案例（4.5%债券按$40转换，股价涨到$65.5→分股后相当$88、债券价值≥$220；被赎回转成股票后股价跌到$7.375、债券价值只剩$27，比原价跌75%）；"华尔街有一些审慎的原则，但问题在于，每当最需要这些原则时，它们却总是被人们遗忘……照我说的去做，不要模仿我的行为"
- **AT&T的范例与反证**：1913–1957年至少发行9批可转换债券（多为股东认购权）——优势：比股票更广的买主（金融机构不许买股票）、利息不到股息的一半；$9股息维持40年（1919–1959），几乎全部转换——"证明了AT&T的稳健性，却不能证明可转换债券具有内在吸引力"——要证明稳健性，需要"普通股市场令人失望时可转换债券结果也好"的例子，"很难看到此类例子"
- **对普通股地位的影响（两个抵消因素）**：并购发行可转换证券（NVF以近$1亿5%可转换债券+权证换Sharon钢铁）使报告每股利润增加；但①稀释可以算出（综合大企业"一直在玩弄可转换证券的花招"——表16-3：Avco、Gulf & Western、ITT、Ling-Temco-Vought、National General等，可转换证券总和与现有普通股相当甚至更多）②乐观市场里完全被忽略
- **普通股向优先股的地位转变**：1956年普通股收益高于同公司优先股；现在正好相反——Studebaker-Worthington：普通股$57，$5可转换优先股$87.5（可换1.5股普通股，价值$85.5，差价很小）；普通股股息$1.20/股（1.5股=$1.80）vs 优先股$5——差价不到1年弥补，此后优先股明显占优；且可转换权"保证了优先股的售价不可能低于普通股组合"——1971年底差价从2点扩大到20点——"这再一次证明，这种转换是有利的，同时也证明，股市倾向于忽略算术"
- **认股权证（股票期权）的定性**：①凭空捏造美元"价值" ②会带走普通股固有价值（优先认购权）转移给权证——以此类推还能发行股息权证、销售收入权证、投票权证，"为什么人们不会这么做呢？"——因为人们对金融业务不太熟悉 ③"权证的存在会使得普通股的价值下降"，而股票+权证组合通常获得更好市场价——普通股股东被愚弄
- **权证的资本筹集功能是幻觉**：公司不可能在权证到期前要求持有者行权；要筹资还得按稍低于市价向股东发行——"权证并不能提供什么帮助，它们只是会使得情况更加复杂"（还要不断要求下调认购价）

## Mental Models
- **《浮士德》的纸币类比**：歌德笔下的指券（assignats）被当做"了不起的发明"，最终失去所有价值——American & Foreign Power权证：1929年市值超$10亿（只出现在资产负债表注释中）→1932年缩水成$800万→1952年从资本结构中消失（公司甚至没破产）；"有魔力的纸币！"
- **两全其美必有其假**：任何"免费午餐"金融设计——先问双方都满意时谁付了代价
- **转换即投机化**：可转换的头寸价值=利息+潜在利润的战略组合；转换的时点往往是股价大涨之后——最不利的时机
- **下跌检验原则**：任何证券的稳健性只看市场下跌时的表现——可转换债券"总体结果总是令人失望"
- **算术会被忽略**：股市倾向于忽略算术——权证稀释、优先股转换差价，市场定价常常错得离谱（差价2点→20点）

## Anti-patterns
- **买牛市后期发行的可转换证券**："总体上讲，牛市后期发行的一类可转换证券必然不能得到满意的收益……悲剧将不可避免，因为股市的大幅下跌，必然会使得人们对这种证券本身的基本安全性产生怀疑"
- **用可转换优先股代替买普通股**：当普通股本身价格不合理时，"用可转换优先股来代表普通股的做法，并不足以使情况得到改善"——"在一些情况下，这种结合能很好地发挥作用，但统计数据似乎表明，它更有可能是一种陷阱"
- **在股价大涨后转换**：Eversharp的基金经理们就是反面教材——被"市场表现"冲昏头脑
- **忽视权证/转换权的稀释**：综合大企业的并购魔术——报告利润增加、实际每股价值被摊薄
- **发行大额权证**：权证相对于已有股份过大→公司有过多优先资本，"公司应该出售更多的普通股"
- **把权证的剧烈波动当投资机会**：Tri-Continental权证$1/32→$75.75（2,420倍）；Ling-Temco-Vought权证1971上半年$2.5→$12.5→$4——投机者的游戏

## Worked Example
**National General权证稀释计算（1971年6月，表16-4）**：
- 3种权证市值$9,400万 ÷ 现有普通股 = 每股$18.80 → 调整后普通股"实际"价 = $24.50 + $18.80 = **$43.30**
- 公司算法（不调整）：$24.50 ÷ $2.33（扣除特殊项目前） = 10.5倍——"明显不合理"
- 正确算法：$43.30 ÷ $2.33 = 18.5倍；扣除特殊项目后$0.90 → **48.1倍**——"稀释后将使得市盈率大幅度增加——这才是合理的"

## Key Takeaways
1. 可转换证券本身无所谓好坏——"这个问题将取决于与单个证券相关的所有事实"
2. 但统计数据无情：可转换权通常以投资质量为代价（1946年：30% vs 9%平均跌幅）
3. 稳健性只用下跌期检验——长牛市中的好表现不说明任何问题
4. "永远不要把可转换债券进行转换"；25–30%止盈只是幻觉的上限
5. 优先股转换权=保底——但差价证明"股市倾向于忽略算术"
6. 权证=凭空捏造的"价值"——算每股真实价必须把权证市值加进股本
7. 适度债券规模的权证可容忍；大额权证=优先资本过多，应卖更多普通股

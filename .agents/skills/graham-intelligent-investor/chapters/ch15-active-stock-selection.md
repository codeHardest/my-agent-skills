# 第15章 积极型投资者的股票选择

## Core Idea
先泼冷水：用基金业绩证明**跑赢市场极其困难**——1960–68年研究显示纽约证交所随机组合整体跑赢同风险级别的共同基金（低风险每年3.7%、中风险2.5%、高风险仅0.2%）。然后给出积极型的三条可行道路：**①格雷厄姆-纽曼式的特殊业务（套利/对冲/廉价股）②以《股票指南》为工具的低市盈率筛选法 ③特殊情况（并购套利）**——并坦承：随机做的特殊交易没有吸引力，"这已日益成为具备必要经验和判断力的专业人士所从事的领域"。

## Frameworks Introduced

- **为什么战胜市场如此之难（两种解释）**：
  - 解释一（有效性）：股价已包含所有重要事实+合理预期——后续变化来自无法预见的进展，即随机的——分析师"在力求对不可预测的东西做出预测"；成百上千专家研究同一股票，价格就是专家共识——如同桥牌锦标赛：所有选手水平相近时，胜者取决于"机会"
  - 解释二（方法缺陷）：流行做法=买前景最好的产业+管理最佳的公司，无论价格多高——这只有在"优秀企业利润无限期高速增长"时才成立；现实中只有极少数公司能长期连续高增长，大多数企业的相对地位不断变化（钢铁业"从贫穷到富有再到贫穷"）
  - 结论：**要么价格有效（研究白费），要么方法有缺陷（正确选股被高估排除）**——"如果聪明的人都在股市中从事职业投资，但还存在既稳妥又不受欢迎的方法，那将十分奇怪。然而，我们自己的职业和声誉，一直是以这种不可能的事实为基础的"
- **格雷厄姆-纽曼法（1926–1956）四种业务**：
  1. **套利**：买入某种证券，同时卖出按重组/并购计划将交换的其他证券——条件：计算的平均回报率≥20%，成功机会≥80%
  2. **资产清理**：购买将在清理过程中收到现金付款的股票
  3. **关联对冲**：买可转换债券/优先股，卖转换标的普通股——头寸接近平价；普通股下跌幅度大大高于优先求偿证券时产生利润；"当熊市中我们'低估证券'业绩不太好时，关联对冲会带来丰厚的利润"
  4. **净流动资产证券（廉价股）**：以低于净流动资产账面值的成本尽可能多地买——价格中不含厂房等资产的价值——购买价一般≤剥离资产价值的2/3；大多数年份至少分散到100种
  - **被终止的业务（教训）**：①购买"明显具有吸引力"的证券（但低于营运资本价值买不到）②"非关联"对冲（所购证券无法与所售股票交换）——10年+跟踪后结论：利润不可靠，没有理由继续
- **积极型投资者的选择框架**：
  - 范围：（1）以稳妥标准看肯定没有被高估（2）似乎肯定比一般普通股更有吸引力
  - 灵活性："允许在大量有利因素中出现一个微小的不利因素"——1970年出现赤字不排除，如果大量利润等因素使股价看上去很便宜
  - 周期性股票时机："如果遵从我们的理念，他将更有可能购买重要的周期性企业的股票——比如钢铁股——当目前的情况不太有利，近期不太看好，而且低股价充分反映了当前的悲观情绪时"
  - **绝对禁令**：不要因对产业/公司的乐观情绪购买高价股（相对于利润和资产而言）

## Key Concepts
- **《股票指南》筛选法（1970年底）**：第一步按最近12个月PE≤9筛出前20种（全册约450种PE<10）；第二步加5条标准：①流动比≥1.5，工业企业债务≤净流动资产110% ②近5年无赤字 ③目前有股息支付 ④去年利润高于1966年 ⑤股价≤有形资产净值120%——20种只剩5种；全册4500家公司中约150家满足全部6项；再按偏好第三次选择（如20%）；加第7条"标准普尔评级≥平均"（8年利润/股息稳定增长排名）→约100种——"质量在平均以上+满足财务标准+低PE+低于资产价值购买=满意投资结果的好前景"
- **单一标准的历史验证**：仅两种方法长期一致有效——①买低PE的重要企业（道指级）②买价格低于净流动资产价值的各类股票（缺点：过去10年机会正逐步消失）
- **八种单一标准试验（1968年底买、1971年6月重估，各30种）**：低PE/高股息/长股息记录/大股本/强财务/低单价/低于前高/高评级——随机90种股票平均跌22%（标普持平、道指-5%），"质量较差的小盘股在牛市期间会被高估，随后不仅损失惨重，反弹也慢，许多永远无法全面反弹"
- **唯一跑赢指数的三类**：①质量最高（A+）的工业企业+9.5%（标普工业-2.4%、道指-5.6%；A+公用事业+14%）——"评级较高的组合在每种情况下都优于评级较低的"②流通股≥5,000万的大公司（持平）③每股$100以上的高价股（略好）
- **商誉巨头（goodwill giants）的势头**：30家商誉≥$10亿且占市价一半以上的公司，1968年底商誉总市值超$1,200亿；1968.12–1971.8平均涨15%，20余种居业绩最佳之列——"规模很大+过去记录好+公众预期增长持续+多年强势市场表现的公司具有很强势头"——即使定量标准看价格很高，市场力量可能在一段时期内主导；IBM反例：30个月内$315→$304；格雷厄姆仍偏爱"资产价值至少占市场价格的三分之二"的股票
- **低价股的品牌悖论**：Cone Mills、Jantzen、Parker Pen、West Point Pepperell（表15-2）售价低于每股净流动资产——著名品牌+土地+机器全部不被市场青睐；"帕斯卡尔说过：'内心或感性能理解的东西，理智不一定能理解'"
- **并购潮的两面性**：1970年并购消息约5,000条（1969年6,000多条）——机会数量大增；但失败交易越来越多（反托拉斯干预、股东反对、"市场条件"改变、进一步研究不利、细节无法一致）——技巧在于"挑选最有可能成功的交易，并且挑选失败后损失最小的交易"

## Mental Models
- **随机选股 vs 加权指数的差**：我们的检验以"一家公司一股"为基础，标普按规模加权——大企业权重大使两者结果大不相同，也再次说明"道指的价格稳定性比'一般的'公司更好"
- **多标准叠加才有效**："只有当所挑选的股票同时满足几种数量或实际标准时，检验结果才会支持我们的建议"——单一有利因素随机挑选只是"好于"相反因素，不够格
- **商誉=市场长期喜爱**："人们很难判断，优异的市场表现在多大程度上来自于'实际的'或客观的投资优势，以及在多大程度上来自于人们长久以来的喜爱"——两者都重要
- **净流动资产法需要耐心**：Burton-Dixie（$20买、NCA$30、账面$50）——1964年3月买入，1967年8月涨到$53.75——3年半赚165%（复利年回报47%）——"有时候，需要有相当大的耐心"

## Anti-patterns
- **买"前景最好的产业"不看价格**：正确性只建立在无限期高速增长的假设上——"只有极少数公司能够显示出长时间内连续的高增长"
- **把二类小盘股纳入组合**：除非满足筛选标准——牛市中高估、暴跌中损失惨重且反弹缓慢
- **随机做特殊交易**：三个1971年案例（Borden-Kayser-Roth并购失败亏12%；Aurora条款调整后年回报约25%；Universal-Marion初始分配后价格跌至$13）——"随机从事此类交易没有吸引力"
- **忽略商誉巨头的势头**：即使价格超出定量标准——但也要注意IBM式反例
- **以单一标准（如低单价）买股票**：低价股"可能会告诫防御型投资者要警惕"，对积极者"总体上是有利的"，但不足以单独作为选择依据

## Worked Example
**《股票指南》筛选全流程（1970年底）**：
- PE≤9：前20种入选（第6家是Aberdeen Mfg.：年终价$10.25 = 每股利润$1.25的9倍；第20家美国玉米公司：$9.5，同为9倍）；10种股价≤$10；推算全册约450种PE<10
- 加5条标准后：20种只剩5种；继续在全册前450种中找，得15种"组合"（表15-1：Aberdeen/Alba-Waldensian/Allied Mills/美国玉米/Anaconda/Anderson Clayton等，多数评级B+，一家A级）
- 第三次选择：从约150种达标股票中按自己偏好选20%
- 再验证：单标准试验中，低PE组跌幅小于高PE组、长期股息组亏损小于无股息组——多标准组合才真正有效

## Key Takeaways
1. 战胜市场极难：1960–68年随机组合跑赢同风险共同基金（低风险年化3.7%）
2. 两种解释都指向：要么价格有效、要么流行方法有缺陷——格雷厄姆-纽曼以特殊方法立足
3. 积极型可复制工具：《股票指南》6条筛选标准（PE≤9+5项财务/盈利/价格标准）→ 约150种 → 偏好精筛
4. 廉价股：价格≤净流动资产2/3、分散100种以上——历史有效（除1930–32），但机会渐少
5. 特殊情况是专业人士的领域——随机参与没有吸引力
6. 商誉巨头有势头（1968–71涨15%），但格雷厄姆偏爱资产≥2/3市价的股票
7. 多标准叠加才支持选择建议

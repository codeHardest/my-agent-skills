# 第4章 防御型投资者的投资组合策略

## Core Idea
防御型投资者的组合策略只有一句话：**资金分散于高等级债券与高等级普通股，股票占比25%–75%，默认对半开，按5%的幅度机械反向再平衡**——不需要预测，只需要纪律。

## Frameworks Introduced

- **25%–75% 股票/债券区间 + 对半开再平衡规则**：
  - 股票资金下限25%、上限75%，债券比例相应反向；标准分配各占一半
  - 再平衡：股票占比升到55% → 卖出1/10的股票转投债券；降到45% → 卖出1/10的债券转投股票
  - 为什么有效：避免在市场日益走高直至危险程度时不断加仓；简单、方向正确、让持有者"至少在对市场变化作出某种反应"
  - 注：耶鲁大学1937年起执行"正常持仓35%"规则，1950年代初即放弃（1969年股票占比61%）——机构也难以坚持，个人反而可以

- **红利/债券利率 2/3 触发规则**（何时把股票提到50%）：
  - 触发条件：道琼斯成分股红利达到债券税前收益率的2/3
  - 1972年数值例：道指900点、单位红利$36、债券收益7%时 → 需债券降到5.5%或道指降到660点（红利不变）才到买点
  - 难点不在复杂，在于"接受它并坚持下去，而不在乎结果可能证明它过于保守"

- **债券选择的两个决策**：
  - 含税 vs 免税：纯数学问题——边际税率>30%（单身应税收入超$10,000 / 已婚超$20,000）选市政债（1972年：Aa公司债7.5% vs 优质市政债5.3%）
  - 长期 vs 短期：取决于能否承受价格波动；代价是（1）较低年收益（2）放弃本金升值

## Key Concepts
- **"风险决定回报"是错的**：目标收益率由"乐于且能够付出的智慧"决定——图省事的消极投资者理应得到最低报酬；"在许多时候，买入廉价证券的实际风险反而更小，获利机会比买常规债券更大"（1965年论断，1970年代利率上行验证）
- **赎回条款的陷阱**：债券发行后即可赎回（赎回价仅高出发行价5%）——基准利率大幅波动时，负面冲击自己承担、有利变化几乎无法受益："我总是赢家，而你总是输家"
- **折价债券 vs 高息票可赎回债券**：折价买低息票率债券更有利——折扣本身（如3.5%票息按63.5%面值出售，收益率7.85%）足以保护赎回不利
- **优先股"本质上是不好的"**：既无债券的法定求偿权，又不能分享公司利润；只在价格跌至不合理时（且仅限进取型投资者）买入——"只可按廉价的交易条件买进，要么就干脆不买"
- **收益债券**：有利则付息、可累计、利息抵税使资本成本减半——安全优于优先股却遭冷落，说明华尔街"忘记历史、抛弃久经考验的原则，却顽固坚持偏见"
- **储蓄存款**：收益与短期高等级债券相等的银行定期存单/储蓄账户，是短期债券的良好替代品

## Mental Models
- **把组合当自动装置而非判断**：对半开是"最简单的万能装置"，不保证最优，但保证不犯大错
- **用税后视角看一切固定收益**：公司投资者买优先股（股息85%免税）、个人投资者买免税债券——同样的现金流，税后结果天差地别
- **警惕"合法但掠夺性"的条款**：赎回条款、新股发行结构——条款设计者永远站在对手方

## Anti-patterns
- **低等级/高收益债券**：总体收益更高但面临价格下跌与违约双重风险；"廉价交易机会需要专门研究和技能"——普通投资者规避为妙
- **追高加仓**：牛市顶部不断增加股票占比——对半开规则正是为此而设
- **忽视赎回条款买高息票新债**：短期可赎回债券让你承担利率下行（价格上涨）的全部损失却拿不到任何好处
- **在恐慌中以不合理低价卖出优质债券**：美国煤气电力债券1928年101发行，1932年恐慌跌至62.5（收益率8%），1946年反弹至等价160——长期投资者本可大赚
- **迷信"机构标准"**：耶鲁都放弃的规则未必错——市场巨大发展让流行方法"不再时兴"，但原则的有效性不以流行度衡量

## Worked Example
**美国煤气和电力公司债券（赎回条款的教科书案例）**：
- 100年期、5%票息债券，1928年以$101发行 → 1932年恐慌中跌至$62.5（收益率8%）→ 1946年强反弹后，5%票息对应价格接近$160
- 此时公司行使赎回条款，仅以$106赎回——债券持有者错过了从62.5到160的全部上涨
- 教训：收益率的"双刃剑"被赎回条款截断——向下风险自担，向上收益被剥夺

## Key Takeaways
1. 防御型组合=高等级债券+高等级股票，25%–75%区间内对半开，5%幅度机械再平衡
2. 回报由付出的智慧决定，不是由承担的风险决定——"不能承受风险就满足于低回报"是流行的谬误
3. 债券选择两步走：先算税（边际税率>30%选市政债），再定期限（能承受波动才选长期）
4. 买债券宁要低息+不可短期赎回+折价，不要高息+立即赎回
5. 优先股只在廉价时买，且只适合进取型投资者
6. 普通投资者规避低等级债券——高收益的背面是违约与波动

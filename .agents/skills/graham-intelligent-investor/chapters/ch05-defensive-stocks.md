# 第5章 防御型投资者与普通股

## Core Idea
防御型投资者选股不靠眼光，靠**规则过滤**：四项可检验的选股标准（分散度、规模质量、股息历史、市盈率上限）把组合限制在大型稳健公司内，并明确排除成长股——因为成长股的"预期"要由投机成分买单。

## Frameworks Introduced

- **防御型投资者普通股四项规则**：
  1. **分散化**：最少10只、最多30只不同的股票——"适当但不过分的分散"
  2. **规模与质量**：每一家公司应大型、知名、财务稳健
     - 财务稳健的操作性定义：工业公司普通股账面价值 ≥ 总资本（含全部银行债务）的一半；铁路/公用事业 ≥ 30%（1971年道指30只成分股全部满足）
     - "大型"：资产或营业额 ≥ $5,000万；"知名"：规模居行业前1/4或1/3
     - 这些标准只是参考性的——"过于执着如此随意性的标准则是愚蠢的"
  3. **股息历史**：连续支付股息至少自1950年起（1971年标准）——用历史支付记录过滤掉投机性资本结构
  4. **价格限制**：买价市盈率 ≤ 7年平均利润的25倍，或 ≤ 过去12个月利润的20倍——"这一限制会把几乎所有成长股排除在外，这正是我们的目的"

- **风险的正确定义**（挑战流行的"波动率即风险"）：
  - 真正的风险 = 价值的损失：证券实际售出时的亏损、公司地位的严重恶化、或买价相对内在价值过高
  - 周期性、暂时性的价格下跌不是风险——除非被迫在此时卖出；判断安全性的唯一标准是"能否按时还本付息"（类比：住房抵押贷款的安全性不问市价波动，只看能否还贷）
  - 以"平均价格波动/波动性"定义风险（Brealey, 1969）对稳健投资决策"更加有害而非有利"——它过于强调市场波动

## Key Concepts
- **普通股的两大优点**（1949年表述，1972年依然成立）：(1) 很大程度上免受通胀损失，债券完全不能提供此保护；(2) 多年平均回报更高——来自更高平均红利+未分配利润再投资推动的市值长期上扬
- **优点的前提**：价格不能过高——1929年买在顶部，25年后市场才恢复元气；1957年普通股再次失去股息率高于债券利率的优势
- **成长股（growth stock）**：过去每股利润增长显著超过平均水平且预计未来持续；专家口径：未来10年利润翻番（年复合7.1%）
- **美元成本平均法（dollar-cost averaging）**：每月投入等额资金——汤姆林森对23个十年期（截至1929–1952）的检验，期末平均利润21.5%（不含股息）；"无论证券价格出现怎样的波动，这种投资法都能使人满怀信心地取得最终的成功"
- **投资组合检查**：每年至少一次，请声望最高的机构评估；但要**预先申明自己的选股原则**——"如果一开始选定的股票组合很恰当，就没有必要频繁或大规模改变"

## Mental Models
- **把"排除"当策略**：市盈率上限不是为了选出好股票，而是为了"不买什么"——先把热门股、成长股、高倍数股票排除掉，剩下的组合自然安全
- **价格与质量是两回事**：好公司≠好投资；"如果投资者以过高的价格买进股票，这些优势就会烟消云散"
- **两害相权取其轻**：1971年底道指900点，格雷厄姆对"此点位的普通股没有多大兴趣"，但防御型投资者"不能忍受不在其投资组合中持有一部分普通股"——全部持有债券的风险更大
- **个人情况决定策略，资金多寡不是**：买入何种证券、追求多高回报，"不能以个人的资金多寡为依据，而要看自己在金融方面的能力——知识、经验和性格"
- **年轻即试错资本**：年轻人应及早开始投资教育与实践；"以尽可能小额的资金，对自己在价格和价值方面的判断进行尝试性检验"——但"不要把自己的精力和金钱浪费在试图战胜市场上"

## Anti-patterns
- **买成长股当防御型策略**：IBM——"最佳普通股"，1961–62年6个月折损一半，1969–70年又跌几乎同样幅度；德州仪器：6年从$5涨到$256（利润40¢→$3.91，股价涨幅是利润的5倍），两年后利润降50%、股价跌80%至$49——成长股"不确定性过高、风险过大"
- **为"额外收入"而投机**：寡妇的例子——缺乏知识经验却追求高收益；"最好是每年从本金中获取$2,000，而不要将一半本金冒险投到投机性活动中去"
- **靠职业智力自信做投资**：医生群体——"处理证券事务方面的无能是众所周知的"：智力自信+获利心迫切，却"没有认识到投资的成功需要付出大量的精力和对证券价值做出专业判断"
- **把波动等同于风险**：一跌就说"股票有风险"——单是市场价格下跌不构成亏损；以合理投资年限衡量、整体回报满意的组合实际就是"安全"的
- **频繁调整组合**：把"送检"当业绩游戏——每年检查一次即可，原则既定，勿大规模变动

## Worked Example
**德州仪器——成长股定价的数学**：
- 6年间股价$5 → $256（+51倍），同期每股利润40¢ → $3.91（+9.8倍）
- 股价涨幅 = 利润涨幅的5倍——"这是此类热门股的一般特征"：市场已把未来多年的增长一次性预付
- 两年后利润下降近50%，股价下跌4/5至$49
- 教训：买入价已包含"完美预期"，任何低于完美的实现都导致双杀（利润跌+倍数压缩）

## Key Takeaways
1. 防御型选股=四条规则过滤：10–30只、大型知名财务稳健（账面≥总资本一半）、连续股息20年+、PE≤7年平均25倍/12个月20倍
2. 把成长股整体排除——即使IBM也会6个月跌一半；"热门"的代价是投机成分
3. 风险=价值损失（被迫售出/地位恶化/买价过高），不是价格波动
4. 美元成本平均法是最好的防御型执行工具：23个十年期样本无一失败
5. 每年请顾问检查一次组合，但先申明原则；组合恰当就少动
6. 策略选择看个人能力（知识、经验、性格），不看资金大小

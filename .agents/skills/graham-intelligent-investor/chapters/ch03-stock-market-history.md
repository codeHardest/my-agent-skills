# 第3章 一个世纪的股市历史：1972年年初的股价水平

## Core Idea
以1871–1971整整一个世纪的价格、利润、股息数据为背景判断当前估值水平：估值判断的标准不是"价格涨了多少"，而是**股票盈利收益率/股息收益率与债券利率的比值**——1972年初该比值已倒挂（1948年股票盈利收益率是债券的3.96倍，如今仅为0.72倍），结论：保守投资视角下估值缺乏吸引力。

## Frameworks Introduced

- **股票 vs 债券相对价值比较法（比值检验）**：
  - 核心指标：盈利收益率（E/P，即市盈率倒数）、股息收益率，与高等级债券收益率对比
  - 历史基准：1948年股息收益率是债券的2倍、盈利收益率3.96倍 → 1972年债券收益率已是股息率的2倍多、盈利收益率比值0.72
  - How：用最近3年平均利润计算市盈率（平滑单年波动）；股息用最近12个月数据；债券用AAA级收益率
  - 应用：比值≥1 股票占优；比值<1 且大幅倒挂 → 估值对保守型投资者缺乏吸引力

- **百年市场三段论**（1871–1971）：
  - 1900–1924：3–5年小周期反复，年均上涨约3%
  - 1924–1949："新纪元"泡沫→1929大崩溃→不规则波动，年均仅1.5%，公众对股票毫无兴趣——物极必反，为最大牛市备好土壤
  - 1949–1968：道指163→995（17年涨5倍，年复合11%+3.5%股息）；1968年12月触顶（S&P 425工业指数118点）——"大繁荣时代在1969–1970年已告结束"

- **估值判断的诚实边界**（重温1948/1953/1959/1964年结论）：
  - 1948（道指180）："从其内在价值看，股价并不算高" ✓
  - 1953（275）："价值含量可取"但过于谨慎——事后看应预见到5年涨100%
  - 1959（584）："股价水平相当危险"——之后1961冲到685、1962年5月跌到536（6个月-27%）
  - 1964（892）："如果1964年的指数还不算过高，那就没有任何过高的点位了"→ 1964后指数先涨11%到995，再跌到1970年632点
  - 教训：时点判断"有趣但实用性有限"，真正有用的是**一致且可控的投资策略**

## Key Concepts
- **19次牛熊周期**（表3-1）：1871–1971年，考勒斯-标准普尔与道琼斯两指数的最低/最高点——历史是周期的集合，不是直线
- **市盈率的历史摆动**：S&P综合指数 1949年6月 6.3倍 → 1961年3月 22.9倍；股息率从7%+跌至3.0%，同期债券利率2.60%→4.50%——"有史以来股票市场公众态度最引人注目的转变"
- **盈利质量恶化信号**：1970年美国公司整体利润率降至二战后最低，大量公司亏损、破产数创近30年之最
- **"呼啸的60年代"真相**：1970年道指收盘价低于6年半前，是1944年以来首次——吹捧的黄金年代只是"系列的小幅上涨继而下跌"
- **不祥之兆与误警并存**：1926–1929的担忧未重演（1970年收盘与1964年11月相当），但1969–1970暴跌后仅一年市场就视而不见——"粗心大意会逃脱惩罚吗？"

## Mental Models
- **用比值而非点位判断贵贱**：900点本身无意义，900点除以利润（18倍）和对比债券收益（倒挂）才有意义
- **公众态度是反向指标**：1949年7%股息无人问津 ↔ 1961年3%股息万人抢购——最明显的转变发生在美国公众对股票态度最两极时
- **把"谨慎"落在操作上，而不是预言上**：1964年三条纪律（不借钱、不加仓、降仓至50%以下并转最高等级债券）远比"点位是否过高"的争论有用
- **数学与雄辩之间**：亚里士多德《伦理学》——"探讨特定论题本身所包含的数量精确性是训练有素的头脑的基本特征"；金融分析工作处于数学家与雄辩家之间，莫追求虚假精确

## Anti-patterns
- **用过去15年的收益外推未来**：1963年创下14%+收益率纪录后，华尔街期待其延续——"一个十分不符合逻辑的危险结论"
- **把回调说成"同一牛市"**：1968年前的后挫（1956–57、1961–62）被舆论归为牛市回调——事后证明1968年就是顶
- **高市盈率买成长股/新股**：1961–62年"成长股"崩盘（IBM从607跌到300），新股/热门股数月内跌90%以上；1968–70年同样剧本再次上演（跌幅90%）
- **新股发行潮作为危险信号**：1968–70年低等级新股买家惨败后，1971年新股发行尚难成潮——没有"可靠的危险信号"≠ 安全

## Worked Example
**表3-3 标准普尔综合指数估值比值（1948→1971）**：
- 盈利收益率/债券收益率：3.96倍（1948）→ 3.20倍（1953）→ 1.41倍（1958）→ 1.10倍（1963）→ 0.80倍（1968）→ **0.72倍（1971）**
- 股息收益率/债券收益率：2.1倍 → 1.8倍 → 0.80倍 → 0.70倍 → 0.44倍 → **0.41倍**
- 结论：即使1971年市盈率（18.0倍，3年平均利润计19.5倍）低于1963/1968年，债券收益与股票收益比率的逆转足以抵消——"与7年前完全一样：估值缺乏吸引力"
- 旁证：华尔街一项"细致研究"预测1975年道指中位数1520点（≈1971年中期的1200点）；实际直到**1985年12月**道指才收于1520点以上——格雷厄姆的怀疑被证实，预测提前了10年

## Key Takeaways
1. 判断市场贵贱，先算三个数：P/E（用3年平均利润）、股息率、AAA债券利率——后两者比值是核心
2. 当债券收益率是股息率的2倍以上时，保守投资者应极度谨慎
3. 历史唯一确定的模式：估值从极端到极端，公众态度随之反转——"它们会起伏不定"
4. 谨慎的判断写进操作纪律（不借钱、不加仓、控仓位），比预测点位有用
5. 1964年的教训：谨慎后市场可能再涨11%——正确≠应时，坚持策略而非追涨
6. 用10年期均值平滑波动看趋势：1900年以来仅两个10年期利润下降（1891–1900、1931–1940），股息从未下降

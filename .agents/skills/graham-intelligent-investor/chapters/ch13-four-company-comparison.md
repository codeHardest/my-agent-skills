# 第13章 对四家上市公司的比较

## Core Idea
用一整章做证券分析的实战演练：随机选取纽约证交所连续排列的四家公司（ELTRA、爱默生电气、Emery航空货运、埃姆哈特），逐一检查盈利能力、稳定性、增长、财务状况、股息、价格历史——最重要的发现是：**四家公司市盈率的差别（9.7倍 vs 45倍）远大于其经营业绩或财务状况之间的差别**，而高市盈率股票的"市场表现"不能作为选择理由——那是投机者考虑的因素。

## Frameworks Introduced

- **普通股投资组合的七项统计要求（第14章完整版的前奏）**：
  1. 相当的规模
  2. 足够强劲的财务状况
  3. 至少在过去20年内连续支付过股息
  4. 过去10年内没有负的利润
  5. 10年内每股利润至少增长三分之一
  6. 股价不高于净资产价值的1.5倍
  7. 过去3年内的平均市盈率不超过15倍
  - 验证应用：ELTRA和埃姆哈特（低市盈率组）**全部满足**——"股价有足够的价值作为支撑，其投资能得到合理的保护……投资者可以认为自己基本上是企业的部分所有者，支付的代价相当于资产负债表中所反映的投资价值"
- **多维度业绩检查清单**（用于任何股票比较）：
  1. 盈利能力：账面价值利润率（ROE）、每股利润增长率、营运收入/销售额
  2. 稳定性：**过去10年中每股利润下降幅度最大的一年 vs 前3年平均**——无下降=100%稳定；1970年坏年份ELTRA和埃姆哈特仅下降8%（道指7%）
  3. 增长：用3年平均利润对比（1968–70 vs 1963–65、vs 1958–60）
  4. 财务状况：流动比≥2、营运资本/债务、长期债务占比、可转换优先股的稀释
  5. 股息：连续支付记录（埃姆哈特自1902年未中断——最佳）；低市盈率组的股息收益率是高价组的两倍
  6. 价格历史：34年最低/最高价之比——道指11:1、埃姆哈特17:1、Emery超528:1——"这表明过去的普通股市场存在着巨大的盈利机会（同时表明1950年前熊市的下跌是多么严重）"

## Key Concepts
- **"商誉巨头"（goodwill giant）**：爱默生电气市值比其余三家总和还大——市场对其无形资产/盈利能力的当期估价超过$10亿（OCR：10万亿美元为误，原文约10亿）；警示案例：仙力牌收音机（Zenith Radio）——快速增长多年、市值1966年达$17亿，但1968年利润$4,300万、1970年下降一半，股价从$89跌到$22.5——"价格的高估带来了巨大的风险"
- **高增长率的规模约束**：Emery的1958年净利润仅$57万、起步规模很小——"当营业额和利润总额已经上升到很高的时候，继续保持高增长会更加困难"；40倍市盈率能否实现取决于未来增长，而竞争加剧（货运代理人和航空公司的新业务竞争）是不利因素
- **市场表现的归因拆分**：分析师偏爱爱默生和Emery的两大理由——①"市场表现"更佳 ②利润近期增长更快；"根据审慎投资的原则，第一个原因并不能作为选择的理由，那是投机者要考虑的因素；第二个原因具有合理性，但其作用有限"
- **高市盈率的支撑力量**："高市盈率来自于市场的强烈判断，因此有相当程度的支撑力量，而这种力量可能会持续一定的时期"——**没有理由期望短期内低市盈率股票表现超过高市盈率股票**

## Mental Models
- **把"市场表现"从分析中剔除**：涨得好的股票不等于好投资——四家公司的对比里，受欢迎与否与基本面优劣无关
- **用"满足7项标准"代替"预测未来"**：对ELTRA和埃姆哈特"我们不做出预测"——"在投资者分散化的普通股名单中，必然会有一些令人失望的股票"——但按标准建立的多样化组合"本身将在随后的年份中有着足够好的表现。至少，长期的经验已经告诉了我们这一点"
- **价值 vs 冒险的自我选择**：选择低市盈率股不是因为它短期会跑赢，而是"自己喜欢价值类投资，而不喜欢冒险类的投资"——"普通股投资策略在很大程度上取决于投资者个人的态度"
- **例外公司的维持成本**：爱默生要在未来"继续保持许多年的例外高速增长"，才能让1970年收盘价"完全得到其随后业绩的证实"——高价的维持需要持续的奇迹

## Anti-patterns
- **用市盈率高低直接判断优劣**：Emery 60倍市盈率（1972年3月为64倍）——对深入研究并得出可靠乐观结论的人"答案或许是肯定的"，但对细心的投资者"答案是否定的——这些人想要事先合理确认，在利润和股市的良好表现方面不犯华尔街通常所犯的过于乐观的错误"
- **把"电子行业"光环当护身符**：曾经作为股市宠儿的电子行业已整体萎缩——"爱默生是一个明显的例外"
- **忽略稀释因素**：爱默生有市值为$1.63亿的低息可转换优先股——分析须假设全部转换（每股利润减少约4%）
- **以"股价翻倍史"推断未来**：34年528:1的涨幅更多是1940–50年代前历史条件的产物，不能线性外推

## Worked Example
**两家低市盈率公司的"被冷落"记录（埃姆哈特）**：
- 1958年：股价为当期利润的22倍（≈道指比率）；此后14年利润增至原来的3倍（道指增加不到1倍）
- 1970年收盘价只比1958年最高价高1/3，而道指高出43%
- 同样的业绩、同样的市场，估值差距拉大——"两家公司似乎在目前的市场上都失去了魅力或'性感'，但是从所有统计数据来看，它们都表现得十分出色"

## Key Takeaways
1. 市盈率差异（9.7倍 vs 45倍）可以远超业绩差异——价格是情绪，业绩是事实
2. 七项统计要求（规模/财务/股息20年/10年无赤字/利润增1/3/PE≤15/价资产≤1.5）是防御型选股的完整清单
3. "市场表现"不是选择理由；近期增长是有限理由
4. 高市盈率有市场支撑力，短期内不必指望低市盈率反超——价值选择是长期立场
5. 满足标准的组合允许个别失望股票——多样化本身提供保护
6. 分析四家公司的方法（盈利/稳定/增长/财务/股息/价格史）适用于任何股票比较
